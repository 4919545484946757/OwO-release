# 不完整拼音整词的覆盖评分

`buyanery` 已能从词典召回“不言而喻”，但曾被“不言而已”等组合挤出首屏。
原因是连贯性评分排除了完整范围的词典匹配边：组合词能获得片段覆盖分，
完整词反而没有。全拼还有精确整词排序保护，不完整拼音则暴露了这一差异。

现在，对文字与音节一一对应、单词条且非临时用户预测的候选，再核对一次词典。
实际存在的整词获得与相同长度词典片段链一致的覆盖证据，每音节 6000 分，
不受子串搜索的四音节上限限制。原有词频、补全/纠错惩罚和用户学习仍参与评分。
没有匹配词典记录的文本不会因此获得整词覆盖分；不会按特定输入或目标词提权。

定向用例位于 `tests/data/incomplete-word-ranking-regression.jsonl`；
引擎测试还覆盖不同预算、分区开关、手动分割和五音节词。
长词样例接受“不可思议的/不可思议地”两种同音表达，不强制无上下文的语义选择。
