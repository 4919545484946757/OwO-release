# 插件管理器

设置中心侧栏选择“插件管理器”，页面分为三个标签。布局使用纵向卡片，长名称、ID 和权限可换行；主要操作保留在卡片底部，维护操作收纳到“更多”，减少小窗口下按钮溢出。

## 已安装

- 顶部统计插件数、启用数和本机版本数。
- 搜索匹配名称、ID、版本、中文权限名称及原始权限 ID。
- 状态筛选：全部、已启用、未启用、待授权。
- 默认每个插件显示当前启用版本，若未启用则显示最新本机版本。“显示历史版本”可管理所有保留版本；筛选在这个可见版本范围内生效。
- 支持从 `.owopkg`、ZIP 或文件夹安装。卡片提供“设置”“启用/停用”，以及“更多 → 详情与权限 / 撤销权限 / 卸载此版本”。
- 启用、撤权和卸载保留现有确认流程。高风险包安装后保持停用；需要独立授权才能运行。启用 Agent 仍有额外隐私确认。
- 必须先停用才能卸载；卸载保留插件用户数据。撤权不删除包文件，重新授权需要重新安装精确包。

## 发现插件

仅在用户点击“刷新在线目录”后访问官方 GitHub，结果缓存在当前设置中心进程内。使用和“已安装”共用的搜索栏，也可勾选“仅显示可更新”。不会在切换标签时重复联网。

目录卡片显示名称、插件 ID、版本、下载大小和以下状态：

| 状态 | 操作 |
| --- | --- |
| 可安装 | 下载并安装 |
| 可更新 | 下载更新，重新核对精确包权限 |
| 已安装 · 已启用/未启用 | 管理本机版本，不重复安装 |
| 本机版本较新 | 管理本机版本，不自动降级 |

版本采用数值比较，避免把 `1.10.0` 误认为比 `1.9.0` 旧；支持预发布版本先后和忽略构建元数据。非标准插件版本仅按字符串回退比较，未知格式不代表已证明兼容。

“详情”列出资源许可证、来源和摘要。在线目录不预先授予权限，也不以目录名称判断包可信：先确认下载，完成来源、大小和 SHA-256 校验，再由现有安装后端检查真实包及权限，并弹出独立授权。更新不继承旧版授权。进度条和取消按钮用于下载；超时、断网或校验失败可重试，不会静默安装。

目录只列出正式发行资源清单中的插件；旧版缺少清单时，只识别具有 GitHub SHA-256 的 `.owopkg`，从规范文件名恢复插件 ID 与版本。程序不上传本机插件清单、配置、用户输入或词库。旧发行目录可能比本机版本落后，不会因此要求降级。

## 恢复与维护

用于检查孤立版本、无效记录和安装事务残留；保持原有审计及逐项确认。恢复不等于重新授权，不能借此绕过权限或 Agent 隐私确认。插件数据路径也在此显示。

## 发布插件

官方源树中的独立插件包可按 ID 限定构建，避免把开发测试和高权限示例一并发布：

```powershell
.\scripts\package_plugins.ps1 -PluginIds org.owo.candidate-glass,org.owo.unicode-palette -OutputDirectory .\artifacts\plugins-release
```

这两个官方插件使用 GPL-3.0-only，独立插件包包含完整 `LICENSE`。发布目录只列入显式选择的包；本机安装状态、个人配置和权限记录不会自动上传。安装包中的附带插件选项继续保留已确认的配置导出流程，仍不导出授权记录。

官方资源清单和安全发布命令见[更新与发行流程](online-distribution.md)，插件能力边界见[插件开发文档](plugins/development.md)。
