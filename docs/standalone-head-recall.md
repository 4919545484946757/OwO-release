# 独立句首候选误去重

`yikexuandefangshi` 的“以可选的方式”已经生成，模型也将其排在第二，
但最终的长句近似变体过滤将它和“一可选的方式”视为冗余，导致无法选取。
此前独立句首置信度例外允许比较，却没有同步覆盖最终去重。

现在为已生成的精确整串候选传递独立句首身份：首分词为单字、后面至少有一个多字词，
字音数量对应，原始分割、完整读音、词语边界及首字后的全文完全相同。
这样的首字备选不再被近似变体规则误删，仍受每方案最多两条、分区及模型质量规则约束。
不放宽句中替字、不同后文、纠错、全单字组合或用户显式偏好的保护。

没有新增拼音答案、汉字白名单、模型请求或搜索预算；只增加内部模型元数据，
不修改公开协议、用户词频、词典、TSF 或模型文件。该修复作用于智能排序结果；
关闭智能排序时基础候选规则不变。

定向验证：五条连续/手动分割及类似表达均从模型后首页缺失变为第二项，
运行错误、模型失败和分页/展开差异为零。当前模型首选仍为“一可选的方式”，
不宣称目标已成为首选。78 条既有控制样例的目标排名未变。
数据集：`tests/data/standalone-head-recall.jsonl`；隔离报告：
`build/sentence-page-layout/reports/head-recall-*`。未执行全量自检。

## 句首先验校准（后续优化）

当没有外部上下文、句子长 5–32 字、最强的同后文首字候选分差不超过 1.0，
且模型自身选出的最优分词都将首字作为独立单字时，比较后文延续证据。
复用已有句中单字校准公式：只折扣 75% 的孤立字先验，仍保留完整的后文条件概率
及 25% 先验；必须有更强的延续证据，才互换这两个原有评分槽位。

每批最多校准一对句首，不新增模型请求；最多重评分两个长度受限的候选。
句首校准生效时不叠加句中校准。非空外部上下文保留原规则，避免误削上下文证据。
已形成整词的首片段（如“一颗”“一个”）不通过独立单字检查；没有汉字/拼音白名单。

真实词典与本地模型的五条原样例均由第二项升到首选；新增八条数词、正常介词
表达仍全部首选，既有 78 条控制样例目标排名未变，分页/展开差异及运行错误为零。
保留第二候选能力，不承诺非空上下文或基础模式也获得同样提权。
报告：`head-calibration-*`、`head-prior-controls-*`；控制数据：
`tests/data/head-prior-controls.jsonl`。
