# 分轮拼音候选质量测试与人工批阅

本轮任务：分阶段测试不同类型的常用词、短语、句子和拼音变体，持续导出问题，
由人工决定哪些属于可接受歧义、标注错误或需要修复的输入体验问题。

## 测试边界

- 起始代码版本：`e7c921c`。记录实际 CLI、词典、桥接库和模型的哈希。
- 默认页长 7、分区开启、纠错开启；基线与 libime 分开跑。
- 独立测试根目录：`build/quality-review-20261029`，不连接日常 Core，不写真实用户词频。
- 不修改候选算法、句子数量上限、模型、原始词典或期望标签来制造通过。
- 自动测试问题均为待人工批阅，不能把某个同音词不是第一项直接认定为缺陷。
- 首屏/Top-K 缺失、扫描截断、消费范围、分页/展开不一致、模型/IPC失败分别记录。
- 手工常用语料与词典抽样自一致性语料分开统计；不把后者当真实输入分布或泛化准确率。
- 只有明确的拼音/编码错误可以修正测试标注，并记录原因；不得删除难例。

## 轮次计划

1. 高频日常双/多字词，检查候选覆盖和同音歧义。
2. 常用短语、办公开发场景、功能性表达。
3. 自然日常句子及长句，观察组合候选保留。
4. 已有词典按词长、词频分层抽样，只检查词典自一致性。
5. 首字母简拼、混拼、末音节不完整。
6. 音节边界、显式撇号和短候选部分消费。
7. 相邻字母交换、漏字母等纠错变体，保留无纠错对照。
8. 显式合成上下文的同音词适应性。
9. 整串/增量输入、5/7/9页长、分区开关对照。
10. 失败项加大扫描预算复核、去重归因与人工问题清单。

视剩余额度继续扩充不同主题、难例和复现轮次，不用机械重复同一批输入消耗额度。
接近最先耗尽的账户窗口约剩 5% 时停止，不使用额度重置。

## 文件与结论

- `tests/data/quality-review/*.seeds`：人工编写的“目标文字|无声调分音节拼音|分类”种子。
- `scripts/new-quality-dataset.ps1`：确定性生成不同拼音变体，不运行/修改算法。
- `scripts/run-quality-round.ps1`：运行显式轮次并记日志；原始 JSONL 报告保留在隔离根目录。
- 人工清单、统计及复现定位在本目录更新；原始报告路径写入索引。

本工作不是 TSF、快捷键、焦点、窗口、插件材质或安装程序的完整自检。
所有语料为合成/已有公开词典数据，不采集真实输入历史、密码或应用上下文。
