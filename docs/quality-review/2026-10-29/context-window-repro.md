# 上下文距离与字段对齐复核

82条合成同音歧义样例，使用当前桥接：

|条件|最终首选|最终首屏|
|---|---:|---:|
|短局部上下文+正确上一段编码 r20|81.7%|91.5%|
|前面加较长中性文字，相关信息仍在末尾 r50|81.7%|91.5%|
|相关信息移到较远处、末尾为中性文字且编码对齐 r52|22.0%|72.0%|

r20与r50的基础和最终首选逐条完全相同，支持“增加较早文字不一定损害最新局部上下文适应”。
r52显著下降，但末尾语境已经不同，原目标不再具有同样强的即时提示；
这是距离/语境边界测试，不应把所有差异直接认定为上下文功能失效。
当前机制偏向局部词边界和n-gram，不能据此声称具备跨段语义理解。

中间r51保留了旧上一段编码，却在其后追加中性文字，导致编码不再对应文字末尾。
该轮属于字段不对齐控制；后续r52将上一段编码改为末尾“内容”的 `neirong`。
两轮原始数据分别保留，不把不对齐控制当正常宿主行为。

证据：`context-near-comparison.json`、`context-distant-comparison.json`、
`context-distant-aligned-comparison.json`，位于 `build/quality-review-20261029`。
