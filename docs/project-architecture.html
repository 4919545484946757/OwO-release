服务与业务调用

编号与服务清单对应；可选路径不代表常驻依赖。

①输入与组合应用加载 TSF，收集编码和焦点，保持预编辑状态。
② → ⑤基础候选Core 解析、查词与分区；本地文件提供词典与配置。
③ / ④ / ⑧可选能力模型排序、受权插件及经插件接入的 Agent。
② → ①呈现与上屏核对请求快照，用户选择后上屏并回传学习。
编号组件 / 形态职责与调用边界
①OwO.TSF.dll · 应用进程内输入事件、组合态、候选窗口与上屏；调用 ②。不加载第三方插件代码
②Core Service · 独立进程解析、候选、学习和管理请求；调用 ③④⑤。候选处理主控
③ModelHost · 可选进程libime 上下文评分。失败时退回基础候选
④PluginHost / 资源插件按清单和逐版本授权提供扩展。独立进程或无代码资源
⑤本地文件owo.conf、.owolx、.owuf、插件数据。不是关系型数据库
⑥WinUI 3 设置 / 安装助手设置、词库、插件和安装步骤。安装授权与运行权限分开
⑦运行启动器启动 ②；条件满足时启动 ③。不参与候选评分
⑧第三方 Agent · 可选通过已授权 Agent IPC 插件交换结构化指令。高风险动作仍需宿主确认
扩展路径：② → ④ → ② → ①；Agent 路径：② → ④ → ⑧ → ④ → ② → ①。设置路径：⑥ → 配置 / 管理后端 → ② 或 ⑤。
