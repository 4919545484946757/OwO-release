3–4. 服务清单与业务调用关系

① 宿主 TSF采集当前组合输入与焦点上下文
② Core校验请求、解析输入、查词与分区
③ / ⑤ ModelHost 与本地数据可选排序；词典、用户学习
① 候选 UI 与上屏同一请求快照渲染；选择后提交/学习
插件路径：② → ④（已授权服务）→ ② → ①；Agent 路径：② → ④ → ⑧ → ④ → ② → ①。设置路径：⑥ → 配置/管理接口 → ②/⑤。运行管理：⑦ 启动 ② 与可用的 ③。
序号组件 / 形式职责与主要调用对象失效边界
①OwO.TSF.dll，应用进程内组合态、焦点、候选窗口、用户上屏；调用 ②不在应用进程运行词典/插件代码
②Core Service，独立进程输入方案、基础候选、学习、配置/词库管理；调用 ③④⑤候选服务中断时不得伪造结果
③ModelHost，独立可选进程libime 上下文评分；由 ② 请求失效时退回基础候选
④PluginHost / 插件进程或资源按清单与授权提供输入方案、主题、符号或 Agent 接口不得直接进入 TSF/Core 进程
⑤本地文件存储配置、词典、词频、插件数据；由所有者组件访问无关系型数据库服务
⑥WinUI 3 设置 / 安装助手设置、词库与插件管理、安装步骤；调用管理后端安装授权与运行权限分开
⑦运行启动器启动和管理 ②、可用时的 ③不是候选评分组件
⑧第三方 Agent（可选）经 ④ 的 Agent IPC 交换结构化命令高风险操作仍受宿主确认限制

API、存储、验收与工程规范见 项目交付说明。本图中的数字与服务清单一一对应。
