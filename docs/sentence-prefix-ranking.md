# 独立句首的模型比较

`yihuowuyunshudesudu` 的解析和“以货物运输的速度”候选原本都存在。
“易货”等跨过首字边界的局部词给错误句子额外连贯性证据，使其领先约两万分。
Core 将同一分词结构的候选按基础分差划为不同置信度层，模型即使更偏好“以”也无法调换。
“为用户提供服务”存在相似问题。

现在仅当两条候选满足以下条件时，允许它们在同一模型置信度层比较：

- 都是完整消费输入的精确组合候选，不是用户明确学习的优先词；
- 音节、输入片段、词语边界、片段数量完全相同；
- 首片段为独立单字，其后至少包含一个多字词；
- 字数与音节数对应，除首字外正文完全相同。

既有普通置信度层和联合字典/句子区的保护均使用这一判定。
这只是允许语言模型判断，不固定“以”“为”或任何汉字优先。
整词、不同后文、不完整/纠错路径、全单字排列、用户学习均不适用。
不改基础评分、解析、词典、句子上限、桥接 ABI 或 IPC 协议，不增加模型请求和搜索预算。
关闭智能排序或模型不可用时，基础结果保持原样；没有宣称基础模式也已改善。

曾尝试在基础连贯性阶段消除句首重叠加分，虽改善新例，却造成四条既有基础目标退步；
该试验已撤回，未包含在最终代码中。当前改动也不是句法分析器：在同后文的首字歧义中，
仍可能继承语言模型偏好；不保证所有介词/动词歧义都正确。
