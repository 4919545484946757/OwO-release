# Agent IPC 连接器：权限与隐私说明

## 启用条件

该插件是高权限进程插件，默认不启用。首次启用以及插件版本变化后，设置中心都会重新显示本说明的摘要。只有勾选“我已理解并明确同意”后，当前精确版本才会获得授权。

授权包含 `agent.ipc`、`input.context` 和 `system.full_trust`。`system.full_trust` 用于连接用户配置的本机命名管道，并不表示第三方 Agent 可以绕过 OwO 的插件授权或替其他插件调用服务。

## 会读取和发送什么

只有拼音串以小写 `v` 开头，并且用户选择候选完整消耗请求或按下 Enter、Space 明确确认时，才会形成 Agent 请求。单独输入、尚未发送过请求的 `v` 可作为普通字母退出；已发送请求的会话不会借此把 `v` 上屏。插件最多发送：

- 去掉首字符 `v` 后的原始输入；
- 随机生成的当前 `session_id`；
- 焦点进程 ID、可执行文件名和窗口类；
- 为连贯对话所需的少量近期上屏文本；宿主仅保留最近 24 个 UTF-16 单元，插件过滤后默认最多发送 256 个 UTF-8 字节；
- 用户选择的结构化指令 ID，或当前候选页码。

默认不读取或发送：

- 窗口标题、完整文档、文件内容；
- 剪贴板、浏览器历史、联系人；
- 键盘中不属于当前 `v` 会话的输入；
- 密码框或已识别安全输入框的局部上下文和应用标识；
- 第三方 Agent 未通过结构化协议返回的控制信息。

用户可以在插件配置页关闭应用标识或局部上下文，并可把上下文上限设为 0。敏感信息过滤不能被绕过；若过滤功能关闭、失败或收到无效 UTF-8，请求会被拒绝而不是原样发送。

## 脱敏边界

插件会再次过滤用户输入和局部上下文。目前会遮盖常见密码、令牌、密钥、凭据字段以及通过校验的支付卡号，并限制字段长度。这是一层降低误传概率的保护，不是对所有自然语言秘密的完整识别。不要在 Agent 模式中输入密码、验证码、助记词、私钥、支付信息或不希望交给第三方的数据。

如果宿主把输入区域标记为敏感场景，插件会清空局部上下文和应用标识。标准 Windows 密码编辑框会被识别；自绘控件若没有暴露安全属性，可能无法被可靠识别，因此用户仍应避免在任何登录或支付界面使用 Agent 模式。

## 第三方风险和责任边界

数据会发往配置的本机命名管道。OwO 不主动联网，但管道另一端的第三方 Agent 可能联网、记录请求、调用其他服务或执行系统操作，其隐私政策和数据保留规则由第三方负责。

OwO 只传递结构化请求、展示结构化结果并返回用户选择，不执行 Agent 的自然语言文本。删除文件、启动程序、修改系统设置、账户、支付、凭据等高风险操作不得仅凭候选选择执行。第三方 Agent 必须在自己的可信界面中再次展示操作对象、影响和风险，并获得用户明确确认。OwO 将 `high_risk: true` 的候选视为不可直接选择，只提示用户前往第三方 Agent 确认。

同一 Windows 用户下的其他进程通常也处于同一用户安全边界。请只连接可信 Agent，并为管道服务器配置仅限当前用户的访问控制。不要把管道暴露为远程命名管道。

## 会话和异常

- 删除已经暂存的候选时，OwO 会先把该候选恢复为原拼音；后续 Backspace 再逐字删除。只有明确删除开头 `v`、按 Escape、候选框关闭、输入焦点丢失或任务完成时，才会取消并结束会话。
- Agent 未连接、超时、崩溃、返回格式错误、过滤失败或会话 ID 不匹配时，不会执行指令。
- 异常不会提交原始输入；原输入保留在拼音预览区，便于重试、修改或退出 Agent 模式。
- IPC 内容不由 OwO 持久化。第三方 Agent 是否保存数据取决于其自身实现。

撤销授权：在设置中心的插件页停用或卸载“OwO Agent IPC 连接器”。停用后新的 `v` 请求会显示 Agent 服务不可用。
