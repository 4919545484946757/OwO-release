# 设置中心通知

各配置页的操作结果统一显示在窗口底部状态栏（原“插件状态已刷新”所在位置），保留提示、成功、警告、错误级别，不再在页内叠加通知框或空白占位。

覆盖输入方案、中文标点、插件配置、配置导入/出、词库管理/编辑、用户词库、发现词库/插件、更新与资源下载。页面内原有静态使用说明仍可作为普通说明文字保留。文件下载进度同时显示在对应功能区及窗口底部，二者绑定同一任务，不再各自维护一套状态。

每个 `MainPage` 将 `ShowStatus` 作为回调传给其页面及子编辑器，不使用应用级静态通知事件，避免跨窗口混发。底部信息采用正文消息显示，可由辅助技术读取。

确认对话框中的风险、失败及 THUOCL 格式清理提示继续留在对话框中，避免被模态遮罩挡住；安装助手有独立流程，不借用设置中心状态栏。

“自动补全编码”采用 WinUI 主操作按钮样式，浅色主题为深蓝底白字，深色主题为浅蓝底黑字；保留悬停、按下、禁用和键盘焦点状态，高对比度时使用系统配色。

定向结构检查：`powershell -NoProfile -File tests/settings_center/SettingsStatusContractTests.ps1`。界面验证应确认词库刷新、编辑校验错误等出现在同一个底部栏，功能区不再产生第二条状态栏。

## 时限与稳定布局

| 信息 | 显示时限 |
| --- | ---: |
| 成功 | 4 秒 |
| 普通提示 | 6 秒 |
| 警告 | 10 秒 |
| 错误 | 15 秒 |
| 下载完成 / 取消 / 失败的任务卡 | 8 / 6 / 15 秒 |

临时消息到期或被关闭后，原位替换为“ⓘ 当前页面名称：页面说明”，不折叠成空白。
兜底提示不可关闭，随当前页更新；下载任务独立显示，不被普通消息覆盖。
采用单调时钟计时，新消息替换旧消息后重新计时，旧计时回调不会提前清除新消息。

底部最小高度 84、最大高度 240，通知行固定高度 64，下载列表最高 144；
这些是 XAML 布局单位，实际屏幕像素随 DPI/窗口缩放变化。长消息最多两行省略，
悬停与辅助技术仍可读取完整内容。多任务在限定高度内滚动，不无限挤压设置页面。

兜底提示和下载卡共用原生 InfoBar 风格：浅色背景 `#EAF4FF`，深色背景 `#D5E9FF`，
文字 `#17324D`。深浅主题均为浅蓝色，高对比度使用系统背景/前景。
成功、警告、错误临时消息保留原生级别配色及图标。

## 统一下载任务

词库、插件以及更新/模型等资源下载复用 `DownloadProgressView`：文件名、字节数、
百分比或未知总量进度、暂停/继续、取消。页内与底部任何一处操作都会同步到另一处。
暂停停止应用继续读取/写入后续数据块，最多等待当前一个数据块；保留当前连接及
已下载数据，不伪造进度。15 分钟的有效传输超时在暂停期间停止计时。

暂停是本次任务内的继续，不承诺跨重启断点续传；服务器若关闭连接，按失败处理并可重试，
不能拼接未经校验的内容。切换设置页时可继续在底部控制下载，关闭设置中心会取消任务。
校验及转换阶段关闭暂停、保留取消。取消或失败清理本次 `.partial`，不会删除已有已验证文件。

仍核对 HTTPS 来源、重定向、声明大小、SHA-256/Git 摘要等原有边界；
下载完成不等于安装授权。插件安装、词库导入及模型切换仍须原有独立确认。

定向测试入口：

```powershell
dotnet run --project tests/settings_center/download_operation_tests.csproj -c Release
dotnet run --project tests/settings_center/online_distribution_tests.csproj -c Release
dotnet run --project tests/settings_center/dictionary_sources_tests.csproj -c Release
```

下载测试使用内存 HTTP 数据，在真实传输循环的首个数据块暂停，验证字节数停止推进、
继续后完整校验、暂停取消唤醒、临时文件清理及已验证目标保留，不安装任何资源。
