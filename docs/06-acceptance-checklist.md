# 06 · 自定义项目验收清单

适用于基于 OwO 二次开发，或引入自定义输入方案、词典与插件。勾选项是交付模板，不表示当前版本已完成所有未来扩展需求。每项需记录“通过 / 未通过 / 不适用”、环境、证据和责任人。

## 范围与构建

- [ ] 明确目标 Windows 版本、输入方案、插件权限、离线能力、可选模型和不做项。证据：需求基线、变更记录。
- [ ] Debug/Release 构建通过，版本号、安装包与源代码提交一致。证据：CMake/.NET 构建日志、发行清单。

## 输入与候选

- [ ] 目标应用中可激活 TSF，输入、纠错、简拼、手动分割、分页、展开、鼠标选择与部分上屏可复测。证据：应用名、输入串、期望候选和截图/回放。
- [ ] 焦点切换、取消、重连、超时和过期请求不会把旧候选覆盖到新窗口。证据：TSF/IPC 定向测试与实机步骤。
- [ ] 固定候选集记录首选、首屏覆盖、Top-K、分页一致性和延迟，并与上一版本比较。证据：开发 CLI 的版本化质量报告。

## 数据与扩展

- [ ] 配置、独立词库和用户词频的增删改、备份、导入导出及重启持久化通过。证据：错误文件与版本冲突案例。
- [ ] 插件最小权限、逐版本授权、取消、超时、非法响应和旧会话结果经过验证。证据：manifest、授权测试与插件宿主日志。
- [ ] 敏感输入框不采集上下文；Agent 展示文本不能直接变成系统操作。证据：安全场景手测与协议拒绝测试。

## 体验与发行

- [ ] 深浅主题、缩放和不同分辨率下，候选框、设置中心和安装助手无明显溢出或闪烁。证据：人工视觉验收。
- [ ] 在干净 Windows 11 环境测试安装、覆盖升级、卸载和失败恢复；模型不可用时仍有基础候选。证据：虚拟机/实机记录及失败注入。
- [ ] 核对发行包 SHA-256、许可文件、迁移说明与已知限制。证据：发布清单及签收人。

自动化通过不能代替真实应用手测。建议附上 `ctest` 结果、设置中心专项测试、CLI 报告、安装导航检查和手测环境记录。
