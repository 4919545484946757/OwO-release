# 06 · 自定义项目验收清单

## A. 范围与构建

- [ ] 固定目标 Windows 版本、输入方案、插件权限、离线要求、可选模型和明确不做项；形成可追溯需求基线。
- [ ] Debug 与 Release 构建通过；版本号、源代码提交、安装包和许可清单一致。
- [ ] 改动只落入所属模块；新增依赖说明许可证、分发权和目标架构。

## B. 输入链路与质量

- [ ] 目标应用中可激活 TSF，输入、纠错、简拼、手动分割、分页、展开、鼠标选择和部分上屏可复测。
- [ ] 焦点切换、取消、重连、超时、快速连续输入时不显示过期候选，也不丢失尚未提交的原输入。
- [ ] 固定测试集记录首选、首屏覆盖、Top-K、分页一致性和延迟，与上一版本及关闭智能模型的基线对比。
- [ ] 模型未启动、插件崩溃、词典停用或配置错误时，有明确退化路径与可理解的错误信息。

## C. 数据与权限

- [ ] 配置、字典和用户学习的增删改、备份、导入导出、重启持久化及版本冲突处理通过。
- [ ] 插件按最小权限声明；安装、启用、升级和高风险操作的确认互不替代。
- [ ] 密码框/安全输入框不采集上下文；Agent 回复文本不能直接触发操作；日志不泄露完整敏感输入。
- [ ] 资源下载核对来源、许可证、哈希、适用架构，并可取消和回退。

## D. 用户体验与发布

- [ ] 深浅主题、缩放、多分辨率下候选框、设置中心和安装助手无明显溢出、遮挡或闪烁。
- [ ] 干净 Windows 11 环境验证安装、覆盖升级、卸载和失败恢复；不擅自删除用户配置。
- [ ] 发行包的 SHA-256、第三方许可、迁移说明、已知限制与实际内容相符。

## E. 未来能力专属门槛（启用时才要求）

| 能力             | 额外验收条件                                              |
| -------------- | --------------------------------------------------- |
| 五笔 / 仓颉 / 外文方案 | 真实词典与许可证、编码光标、候选消费范围、私有学习命名空间、目标应用实机兼容；切换方案不能污染拼音数据 |
| 新模型后端          | 格式和架构校验、内存/CPU 预算、低端机延迟、失败回退、旧版资源保留                 |
| 跨平台 UI / 输入层   | 焦点、安全输入、组合态和上屏等价性；Windows TSF 回归不下降                 |
| 在线词典/插件目录      | 目录真实性、下载哈希、权限逐版本确认、断网及取消行为、许可与下架处理                  |
| Agent 扩展动作     | 结构化命令 ID、会话匹配、脱敏失败即拒绝、危险动作宿主二次确认                    |

计划保留 `ctest`、设置中心专项测试、开发 CLI 质量报告、安装向导只读导航检查和至少一组真实应用手测记录。
