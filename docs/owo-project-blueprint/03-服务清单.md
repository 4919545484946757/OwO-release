# 03 · 服务清单与扩展边界



## 当前组件

| 编号  | 组件、位置和状态                           | 所有职责                                          | 依赖 / 失效边界                       |
| --- | ---------------------------------- | --------------------------------------------- | ------------------------------- |
| ①   | `OwO.TSF.dll`；应用进程内；当前             | 按键、焦点、组合态、候选窗口、上屏，向 ② 发送请求                    | 不加载第三方代码；焦点变化后丢弃旧快照             |
| ②   | `owo_core_service.exe`；当前用户后台；当前   | 输入方案调度、基础候选、纠错、分区、学习和插件调用                     | 基础输入依赖可用词典；不等待 ③ 才显示基础候选        |
| ③   | `owo_model_host.exe`；独立进程；可选       | libime 上下文排序和模型推理隔离                           | 超时、崩溃、资源缺失时 ② 使用基础排序            |
| ④   | PluginHost / 资源插件；按需，输入方案为实验       | 授权插件调用、候选主题、符号、Agent IPC、方案示例                 | 逐版本授权；插件结果不能直接绕过宿主上屏规则          |
| ⑤   | 本地文件资源；当前                          | `.owolx` 词典、`owo.conf` 配置、`.owuf` 学习库、插件和模型资源 | 不是关系型数据库；用户学习由 ② 串行拥有           |
| ⑥   | `OwO.Settings.exe`；按需；当前           | 设置、词库/插件管理、安装助手与下载入口                          | 设置与运行权限分开；高风险动作仍需明确确认           |
| ⑦   | `owo_runtime_launcher.exe`；启动阶段；当前 | 准备路径、启动 ② 和可用的 ③                              | 不执行词典查询或候选评分                    |
| ⑧   | 用户选择的第三方 Agent；可选                  | 经 ④ 接收脱敏请求并返回结构化结果                            | 不属于 OwO 内置服务；执行类高风险动作不能由输入法直接授权 |

## 关键运行链

1. ① 接收输入并记录焦点/请求代数，② 解析并查询 ⑤，先返回基础候选。
2. ③ 可对同一请求补充评分；② 和 ① 均需核对请求身份，过期结果不得覆盖新输入。
3. 用户选中候选后，① 上屏并通知 ②；② 更新 ⑤ 的学习数据。插件不直接写宿主用户词库。
4. ④ 仅在安装、启用和授权后参与。Agent 路径为 ② → ④ → ⑧；错误或取消须保留原输入。
5. ⑥ 通过配置/管理后端修改设置与词库，不应直接改写 ② 正在使用的 `.owuf`。
