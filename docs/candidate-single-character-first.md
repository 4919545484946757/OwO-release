# 完整单字拼音的逐页分区顺序

设置中心 → 候选 →「完整单字拼音时单字区优先」，默认开启。

在全拼方案、候选分区开启且每页至少 4 项时，若解析图存在覆盖全部原输入的完整单音节路径（如 `liang`，同时可能存在 `li'ang`），每一页先显示单字区，再显示多字区。展开列表沿用同一逐页顺序。关闭此开关后，各页使用多字区在前、单字区在后的通常顺序，不关闭候选分区本身。

纠错恢复出的完整单音节（如 `chnag` → `chang`）同样服从此开关，并继续保留 `ch'na'g` 等原分割候选；不改写用户实际输入的拼音。

只调换区域位置，不交换数量配额，不改变区域内部排序，也不扩大搜索预算。奇数页仍保持多字区向下取整、单字区向上取整；某个来源不足时沿用原有补位规则。其他拼音、缩写、精确编码和插件输入方案不受影响。

配置 schema 16 新增布尔值 `candidate_single_character_first_enabled=true`。schema 1–15 读取时使用默认开启值，不覆盖其他配置；保存时升级到 schema 16。原子保存、热加载及缓存代数失效沿用公共配置机制。新选项接入搜索、手动保存、自动保存和候选页重置；未使用全拼或候选分区关闭时，设置入口禁用但保留偏好。

专项测试：

- 配置开关往返、旧 schema 15 迁移、schema 16 缺失或非法值拒绝，以及旧 schema 14 标点迁移。
- 配置后端 `set-all` 新增末尾可选参数，保留旧参数数量的兼容性。
- Core 独立配置热加载测试覆盖每页 4/5/7/9 项、开关两种状态，至少三页的分区顺序、前两页的奇偶配额，以及展开结果与逐页拼接完全一致。
