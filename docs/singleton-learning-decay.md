# 单次学习记录的快速衰减

只选择一次、未重复确认的记录不再无限期保持优先。规则不依赖任何具体拼音或词语，作用于全局、当前输入及语言上下文三种学习分。

| 距首次记录时间 | 行为 |
| --- | --- |
| 0–约 10 秒 | 保留即时学习效果；学习加分随时间下降 |
| 约 10 秒后 | 撤销用户词强优先及额外用户词基础奖励，不再因此越过分区或模型置信度规则 |
| 30 秒 | 单次学习加分降至初始值约 25% |
| 60 秒及以后 | 单次学习加分为 0；词条与原始计数仍保存，可作为低优先候选 |
| 至少两次确认 | 使用原有灵敏度、饱和加分及上限竞争衰减规则，不受本规则的秒级衰减影响 |

这是优先级消退，不是删除自定义词库。已有词典候选继续使用词典和连贯性证据，过期用户副本不得覆盖它的结构。重复选择会重新确认为稳定词频；不会通过查询、翻页、重启或保存刷新首次记录时间。

Core 的候选缓存加入 5 秒时间代数，因此后续查询能看到衰减，不能永久命中旧顺序。已经显示且用户没有继续操作的候选不会因后台计时突然跳动。系统时间回拨按失效处理，不延长单次优先期。

用户词频格式升级为 OWUF v4，在校验和覆盖内保存首次单次观察的秒级时间；仍可读取 v1–v3 及备份。旧格式没有时间戳：计数为 1 的历史项保留但不重新授予即时优先期，重复项保持稳定学习效果。首次正常保存后写入 v4；不在加载或查询时写回用户数据。旧版 Core 不能读取 v4，回滚须一起恢复升级前的词频备份。

测试使用可注入时钟，无需真实等待，覆盖强优先截止、30/60 秒衰减、重启持久化、别名、重复确认、候选保留、旧格式迁移及缓存失效。
