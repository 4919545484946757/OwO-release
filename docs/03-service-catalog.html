03 / SERVICE CATALOG

服务清单

编号与技术架构图、调用关系图一致。这里的“服务”同时包含进程内组件、本地进程和数据资源，不意味着八个网络服务。

运行组件

①TSF 与候选窗口

OwO.TSF.dll · 应用进程内 · 必需

接收按键、维护组合态与焦点、显示候选和执行上屏；向 ② 发出带请求身份的候选请求。

src/tsf/ · Direct2D / DirectWrite

②Core Service

owo_core_service.exe · 当前用户后台 · 必需

输入方案调度、基础候选、纠错、词库查询、分区、学习与插件调用的主要所有者。

apps/core_service/ · src/engine/ · src/ipc/

③ModelHost

owo_model_host.exe · 可选

libime 上下文评分。未就绪、超时或失败时，② 仍应提供基础候选。

apps/model_host/ · src/model/

④隔离插件

PluginHost / 资源插件 · 按需

候选主题、符号、实验性输入方案或 Agent IPC。每版本按清单授权；第三方代码不进入 ① 或 ②。

src/plugin/ · plugins/

⑤本地存储

文件资源 · 无数据库服务

词典、配置、用户学习、插件数据及模型文件。写入归对应所有者管理，不由 UI 直接改写正在使用的词频库。

.owolx · owo.conf · .owuf · settings.json

⑥设置与安装助手

OwO.Settings.exe · 按需

WinUI 3 设置、词库和插件管理；安装助手负责选择、确认与进度反馈。

apps/settings_center/ · apps/setup_center/

⑦运行启动器

owo_runtime_launcher.exe · 启动阶段

准备路径并启动 ②；模型条件满足时启动 ③。不是候选计算或模型推理服务。

apps/runtime_launcher/

⑧第三方 Agent

外部软件 · 用户自选

只经已授权的 ④ Agent IPC 插件交换结构化请求、状态和命令；风险操作仍由宿主确认。

include/owo/agent/

依赖与退化

故障 / 条件预期行为验证重点
③ 未启动② 的基础候选可用不等待模型才显示首屏
④ 未授权或超时拒绝插件结果，不影响内置拼音不执行旧命令，不清空原输入
⑤ 基础词典缺失或损坏启动或查询报明确错误不把停用词典误当作删除运行依赖
焦点或请求代数变化① 丢弃旧结果分页、展开与首屏快照一致
