# 随包插件与安装选项

0.2.6 随包仅包含：

| 插件 | 版本 | 随包启用状态 |
| --- | --- | --- |
| OwO 亚克力候选框 | 1.4.1 | 开启 |
| OwO Unicode 符号列表 | 1.0.0 | 开启 |

安装助手的选项页默认勾选“安装随包插件与配置，并恢复随包启用状态”。取消勾选不安装随包插件，也不改变目标电脑已有插件。命令行安装脚本不自动导入插件。

## 内容和隐私边界

`bundled-plugins/manifest.json` 记录插件 ID、版本、名称、启用意图、包与配置摘要。`packages/` 仅含所选插件版本的 `.owopkg`；`config/` 仅含本次选中插件的当前 `settings.json`。亚克力现有深浅色配置随包保存，Unicode 没有自定义配置时使用插件默认值。

不复制原电脑的 `authorizations`、活动记录、安装记录、历史配置备份、日志、用户词库、Agent 会话或上下文。打包前应检查声明式配置中是否含有个人信息；本次配置为亚克力外观参数。打包不会修改本机插件。

## 安装和授权

每个新插件均通过宿主原生 `inspect-install` 重新检查。用户先阅读权限、信任与免责告知并勾选确认，再对该 ID、版本和清单摘要单独授权。默认勾选的安装选项不是权限授权。拒绝某个插件会跳过该插件，输入法本体继续安装。

原生 `install-risk` 按当前权限机制安装到停用状态、生成目标电脑的新授权；配置验证完成后，再根据随包意图调用正常的激活接口。不会绕过宿主的高权限机制。Agent 隐私提示仍保留在通用导入机制中，但本次发行包不含 Agent 插件。

同 ID、同版本已存在时保留目标电脑的配置、授权和启用状态，不重装、不覆盖。新版本安装时也不覆盖已存在的共享插件配置。权限、摘要或配置检查失败时，不激活失败的新插件；可在设置中心查看、撤销或卸载。插件导入失败不应把已成功完成的输入法安装报告为失败，详情中会记录结果。

包和配置经过路径、链接、大小及 SHA-256 检查，授权后再次核对摘要；权限授予与原生安装绑定的清单摘要一致。校验不等于发布者签名，不能替代用户风险判断。

## 开发打包

```powershell
.\scripts\package_release.ps1 -Version 0.2.6 -BundledPluginStore "$env:LOCALAPPDATA\OwO\InputMethod\plugins"
.\scripts\package_setup.ps1 -Version 0.2.6
```

`export-bundled-plugins.ps1` 默认仅选择上述两个 ID，输出目录必须不存在，且不得与插件仓库重叠。插件 ZIP 使用宿主可独立读取的存储格式。外层发行包的 `SHA256SUMS.txt` 同时覆盖插件清单、包与配置。

定向验证包括隔离仓库中的拒绝授权、原生安装与启用、配置恢复、已存在版本保留、目录越界、重复身份、内容篡改及授权后篡改；安装助手导航验证不执行安装或授权。
