# OwO 0.2.7

- 随包插件风险提示合并为单个窗口，可展开查看每个插件的权限、隐私、风险及启用状态；每项需独立勾选授权。
- 插件安装、启用及 Agent 隐私提示支持记住风险详情的折叠状态；不跳过明确授权，不对新版本或新权限自动授权。偏好仅存于本机，不随安装包分发。
- 优化完整拼音分割和句子评分，“保留当前改动并打包上传”“将配置”等候选不再被较弱分割压至下一页。
- 包含此前的词库管理、插件管理、下载控制与界面改进。
- 修复用户学习词被分区排版压后、弱同音模型候选越过词典置信保护，以及联合评分与展示标签互相覆盖的问题。
- 更新配置迁移、展开分页和重放测试夹具；全量原生套件、设置中心及真实词典回归检查通过。

安装包仅附带亚克力候选框和 Unicode 符号列表。已有插件保留本机配置与启用状态。
平台：Windows 11 x64（包含 x86 TSF 兼容组件）。请校验 SHA256SUMS.txt 后安装。
