# OwO 0.3.1

- 全拼设置按功能分区；快捷键和中文标点在宽窗口使用紧凑双列，窄窗口使用单列。
- 插件管理器按启用状态分区并显示授权标签，点击卡片直接进入相应版本的配置页。
- 修复词库编码补全的保存反馈，保留候选框在更新拼音时的展开状态，避免滚轮误改未展开的设置下拉栏。
- 英文输入与五笔 86 发布新版插件。另提供亚克力候选框、Unicode 符号列表和 Agent IPC 连接器的独立包；插件以自身名称作为发行页标签，不随主程序自动授权。

适用 Windows 11 x64，含 x86 TSF 兼容组件。安装包可选安装亚克力候选框和 Unicode 符号列表，使用仓库内的默认配置，仍需明确授权。安装前请核对 `SHA256SUMS.txt`。安装包不分发本机用户配置、词频或插件授权。
