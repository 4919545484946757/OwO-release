# OwO 0.2.9

- 新增模型管理器：添加、编辑、启用和删除用户自己的 HTTPS Chat Completions 兼容模型 API，设置默认模型、语言、超时与输出上限。
- 新增选区大模型功能：仅在选中文字后按 `v` 打开四类功能菜单，数字键选择翻译、润色、代码纠错或内容生成；成功后直接替换选区，不在候选框预览结果。
- 润色与代码纠错分别提供三档设置；翻译按首选、次选语言切换。
- 功能默认关闭，启用需隐私确认；API 密钥由当前 Windows 账户加密保存，网络请求在独立辅助进程中处理。失败、取消或焦点/选区变化时保留原文。

仅本地编译打包，按用户要求未运行本次测试、未上传。此前开发阶段的定向测试不代表本安装包已完成发行验证；真实模型效果需使用用户自己的服务验证。

安装包仅附带亚克力候选框与 Unicode 符号列表，不包含模型 API 密钥、用户词库、应用上下文或原机器授权记录。

平台：Windows 11 x64，含 x86 TSF 兼容组件。安装包未进行商业代码签名。
