# OwO 0.3.2

- 改善部分应用输入框的兼容性。控件无法验证是否支持高级编辑时，调用 `v` 高级编辑需先确认是否信任当前窗口；明确受保护的控件不会开放该操作。
- 在支持的文本控件中，`Ctrl+Z` 撤销最近一次候选上屏后，可恢复原拼音并重新选词。回撤记录仅保留最近一次，10 秒后失效。
- 改善简拼与混拼候选，新增 `-` / `=` 默认翻页键；`v` 预览只在后面有拼音时显示加号。
- 设置搜索支持页面名称、模糊匹配和分类显示，并改善搜索框内使用 OwO 输入的兼容性。
- 安装进度页新增使用提示；卸载向导支持选择保留用户数据和查看进度，标题栏适配明暗主题。

适用 Windows 11 x64，包含 x86 TSF 兼容组件。亚克力候选框和 Unicode 符号列表可随安装包选装，仍需用户明确授权。安装包不包含本机用户配置、词频或插件授权。请使用 `SHA256SUMS.txt` 核对下载文件。
