# OwO 0.2.8

- 调整词频学习优先级：仅消耗部分拼音的学习词不再越过完整匹配候选；同完整度的学习提权保留，基础排序和智能排序均适用。
- 修复中间声母被当作独立音节导致整句候选缺失的问题，如 `zhemzuodehua` 可生成“这么做的话”。
- 支持多个局部简拼与末尾不完整拼音协同恢复；`zhemshuodeh`、`zhemshuodehu`、`zhemshuodehua` 可生成“这么说的话”。恢复依据已安装词典，不硬编码目标词，并限制查询与中间状态数量。
- 修复安装来源确认提示：未勾选底部来源确认时，点击灰色“安装”可触发抖动及红色波浪线；反馈不会绕过授权或执行安装。
- 更新开发启动脚本：编译当前工作区并启动测试内核，五笔开发插件部署改为显式可选，不隐式授予插件权限。

安装包仅附带亚克力候选框和 Unicode 符号列表；已有插件保留本机配置与启用状态，新插件仍需明确授权。

平台：Windows 11 x64，包含 x86 TSF 兼容组件。支持离线基础输入；需安装“中文（简体，中国）”基本输入支持。

安装前请核对 `SHA256SUMS.txt`。安装包未进行商业代码签名；用户词频、应用上下文和原机器授权记录不随包分发。
