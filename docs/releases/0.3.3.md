# OwO 0.3.3

- 全拼新增可选的「句法搭配（实验）」：在离线候选中参考主谓、动宾、定中等跨词关系。默认关闭，基础输入不依赖模型。
- 实验性的 RIME-LMDG 接入改进了跨词动宾、定语从句、「了／过／着」和「将／把」等结构的排序。仅开发入口显式加载本地模型；安装包和资源目录不分发该模型。
- 模型管理器支持本地模型下载和对话调试，并保留选区大模型功能。自动生成 0 号候选暂缓，现有模型配置保留。
- 改善配置页搜索、候选数字键设置及插件导航。词库卡片边框和底部操作区适配明暗主题；设置中心原生标题栏按钮跟随当前主题。
- 安装进度的使用提示改为轮播展示。

适用 Windows 11 x64，包含 x86 TSF 兼容组件。安装包继续提供可选的亚克力候选框与 Unicode 符号列表；新插件仍需授权，不包含本机配置、用户词频或授权记录。用 `SHA256SUMS.txt` 核对下载文件。
