## 首轮失败及解决方式

首轮 CTest 为 80/90；未忽略或排除失败用例。

- 用户词：生成池与最终页面规范化保留已确认学习词优先；字典身份与独立句子槽位同时保留。
- 模型置信：缩小同读音弱同音词的可交换置信带；不同完整分割不复用同音词置信门槛，使用独立覆盖证据保护；排除明显更弱的碎片重分词种子。
- 联合分区：比较总分后重新标注目的槽位，而非用展示标签撤销排序；跨页保持分割多样性。
- 解析先验：只对没有终端字典覆盖证据的孤立句尾适度减弱，保留真实重叠搭配证据。
- 过期夹具：旧配置不混入新版字段；展开模拟响应提供合法分区；CLI 部分上屏索引适配双句子候选。
- 合同冲突：统一已确认学习词可优先、基础正确句仍需保留的规则，不同时要求相反排序。
- 模型协议同时验证异步更新与已细化缓存；后者无需虚构一个 model_pending。
- 跨页检查按实际剩余分割验证，不要求已耗尽分割继续产生候选；独立计数确认两种分割尚有剩余时必须多样化并延续顺序。
