# OwO 0.2.6

适用于 Windows 11 x64，附带 x86 TSF 兼容组件。安装需要中文（简体，中国）基本输入支持，但不需要更改系统显示语言。

## 本次更新

- 插件管理器：已安装、发现插件、恢复与维护三个标签，支持名称/ID/权限搜索、状态筛选和历史版本管理。
- 官方插件目录：显示安装/启用/可更新状态，提供进度、取消、完整性校验和独立的风险、权限确认。在线目录不自动安装、启用插件或继承旧版授权。
- 通用设置：检查 GitHub 正式版，确认后下载安装助手；支持词库、模型资源目录。词库导入有预览，模型仅下载、不自动切换。
- 包含此前的候选生成、拼音分割、纠错、上下文及界面修复；输入链路保持离线可用。

## 下载内容

- `OwO-Input-Method-0.2.6-windows-x64-Setup.exe`：推荐的安装助手。
- `OwO-Input-Method-0.2.6-windows-x64.zip`：便携安装载荷与脚本。
- `OwO-Input-Method-0.2.6-source.zip`：对应源代码。
- 亚克力候选框 1.4.1、Unicode 符号列表 1.0.0：独立 `.owopkg` 插件包；安装助手同时提供可选附带插件导入。
- `owo-resources.json`：供设置中心读取的官方资源目录。本次只发布上述两个插件，不包含私人词库或额外模型下载项。

安装包保留已有同版本插件的本机配置及启用状态；新插件仍需逐包确认。插件包无需执行第三方代码。输入内容和用户词库不会因检查更新而上传。

## 安全与许可

当前未进行商业代码签名。请核对官方仓库及 `SHA256SUMS.txt`，不要把 SHA-256 校验等同于发布者签名或安全审计。插件摘要同时列于资源目录，GitHub 资产也提供摘要。

OwO 与官方插件：GPL-3.0-only；libime/Fcitx5Utils：LGPL-2.1-or-later；其余依赖许可包含在安装载荷的 `LICENSES` 目录。卸载默认保留个人配置及数据。
