# OwO 0.3.0

- 安装版新增“调试与性能”：关联 TSF、Core、ModelHost 请求，测量排队、IPC、解析、纠错、词典查询、候选生成/分区和绘制提交耗时。
- 首批可用、精化完成和模型应用分别统计，提供 P50/P95、单请求时间线和本地 JSON 报告导出，方便跨设备定位迟缓环节。
- 采样默认关闭，显式限时开启，绑定设置中心进程；不记录输入/候选原文、应用上下文或密钥，不自动上传。阶段嵌套、缺失记录和采样自身开销均有说明，见[使用文档](../candidate-performance-debugging.md)。
- 保留模型管理器及选区大模型功能，并包含 0.2.9 后的插件目录、导航及过期配置编辑器一致性修复。
- 同步安装、卸载、设置中心和打包入口版本为 0.3.0。

仅随包提供亚克力候选框和 Unicode 符号列表及其当前配置/启用意图；新安装仍需本机授权，不复制原机器的权限记录、API 密钥、用户词频或诊断会话。

平台：Windows 11 x64，包含 x86 TSF 兼容组件。安装包为 Setup 引导 WinUI 3 安装助手，未进行商业代码签名。

此前调试功能已通过 25 项托管检查、12 项实际 WinUI 检查和原生计时合同。本次进行版本更新、Release 编译和打包完整性校验，不执行全量自检、真实设备性能基准或实际系统安装/卸载测试；不上传发行版。
