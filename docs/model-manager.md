# 模型管理器与选区大模型

此功能自 0.2.9 起加入安装包；已发布的 0.2.8 安装包不包含此功能。
它与本地 libime 排序、词频学习以及第三方 Agent 插件独立，不会让普通按键请求云端模型。

## 配置与使用

1. 用 `open-owo-settings.cmd` 更新并打开开发版设置中心，进入“模型管理器”。
2. 添加模型：显示名称、HTTPS API 基础地址或完整 Chat Completions 地址、模型 ID、API 密钥。
3. 设为默认模型。可编辑、启用/停用、删除模型；“测试连接”经单独确认后仅发送固定测试文字，可能产生费用。
4. 设置首选/次选语言、润色档位、代码纠错档位，以及超时、输出 Token 上限。设置即时保存；添加、删除与隐私授权仍需明确操作。
5. 开启“选区大模型功能”，阅读并确认发送目的地和隐私提示。默认关闭。
6. 在已加载新版 OwO 的可编辑输入区选中文字，按 `v`，再按 `1`–`4` 或点击功能：

| 数字 | 功能 | 行为 |
| --- | --- | --- |
| 1 | 语言翻译 | 模型判断选区主要语言：不同于首选语言时译为首选语言；相同时译为次选语言 |
| 2 | 语言润色 | 按用户设置的一至三档处理 |
| 3 | 代码纠错 | 按用户设置的一至三档处理并生成注释 |
| 4 | 内容生成 | 将选区作为指令，结合允许的局部上下文和应用名称生成文本 |

支持主键盘与小键盘数字。成功后直接替换原选区，不再预览结果；不会改动选区之外的文字。
等待时可按 `Esc` 取消；失焦、修改选区或继续正常输入也会取消本机操作。
失败时保留原文，提供重试/取消。无选区、按住修饰键、功能关闭或安全性无法确认时，不启用此菜单；普通 `v` 及现有 Agent 模式保留原行为。

旧应用进程可能仍加载旧 TSF DLL，请保存后完全退出并重新打开测试应用。仅打开新标签页不一定会加载新版。

## 档位

- 润色一档：不改原意，只完善字词、语法。
- 润色二档：不改原意，结合上下文和应用环境适配文体、格式和排版。
- 润色三档：可优化语义、排版，并按完成度合理扩写；提示模型不得虚构事实。
- 代码一档：按上下文修复必要符号、变量声明等语法问题并加注释，不改变算法和业务逻辑。
- 代码二档：进一步修复逻辑错误并加注释，保持选区外接口约定。
- 代码三档：允许有依据的算法优化，重点检查兼容性、边界、复杂度及负面影响并加注释。

结果是纯文本；可以包含代码、Markdown 或换行，但不直接设置 Word 等应用的字体、样式或富文本对象。
模型判断、翻译、润色和代码结论都可能出错；本功能不会实际编译或执行代码，请人工核查，必要时使用目标应用的撤销功能。

## API 兼容范围

当前接入 HTTPS Chat Completions 兼容接口：`model`、`messages`、`stream:false`，读取 `choices[0].message.content`。
可选 `max_tokens` 或 `max_completion_tokens`，用于兼容不同提供商。未指定或内置默认模型；模型 ID 与调用权限由用户自己的服务决定。

参考：[官方 Chat Completions 请求/响应文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。
并非所有供应商都兼容此接口；专有协议、自定义认证头、需要查询参数的接口暂未实现。
不自动跟随重定向，不允许 HTTP、URL 内嵌密钥/用户信息或查询参数，不配置禁用 TLS 证书校验的选项。

## 权限与隐私

- 只有用户选中文字后打开菜单、再明确选择功能，才会向所配置模型发送请求。
- 最多发送选区 8192 个 UTF-16 字符、同一输入位置附近不超过 2048 个字符，以及当前应用程序文件名；不发送文件完整路径、截图、历史跨应用上下文或剪贴板。
- 局部上下文可关闭。敏感范围、密码框、私密输入、只读位置和无法确认安全的位置不读取。
- 发送前对常见密钥、私钥及口令模式进行保守拦截；这不是完整 DLP，不保证识别全部敏感信息，请勿选取真实凭据。
- 第三方服务可能保存、处理内容并收费。取消本机操作不能保证撤回已发送的数据或费用。
- 只返回和插入文本；不暴露执行程序、文件操作、账号或系统设置接口，也不处理模型工具调用。
- 常见终端进程禁用此功能。不要在 IDE 内嵌终端或会自动执行换行的输入区调用；宿主可能对插入文本赋予特殊行为。
- API 密钥由 Windows 当前账户 DPAPI 加密，存放于配置目录同级 `models/profiles.json`；不写入普通 OwO 配置、配置导出、发行包或主动诊断日志。加密文件不能当作跨账户/跨电脑密钥备份。
- 结果到达后重新核对焦点、选区边界、原文及输入权限；不匹配时丢弃，避免覆盖后续输入。生成结果不自动加入用户学习词库。

## 架构与调试

TSF 只负责安全选区、菜单、取消和最终替换；联网与密钥解密运行在独立的一次性辅助进程中。
辅助进程复用设置中心的自包含载荷，通过 `--text-assistant-host <随机管道名> --parent-pid <PID>` 启动，不创建设置窗口。

IPC 使用当前用户命名管道，客户端校验服务端 PID，服务端校验调用进程 PID。采用长度上限为 128 KiB 的小端四字节长度前缀：

```text
OWOTEXT1
translate | polish | code | generate
选区 UTF-8 的十六进制
局部上下文 UTF-8 的十六进制
应用文件名 UTF-8 的十六进制
```

每字段独占一行，末行后有换行。响应为三行 `OWOTEXT1`、`OK` 或 `ERROR`、UTF-8 文本的十六进制。
状态和操作使用固定枚举，不从模型自然语言解析控制指令。协议版本不符、超时、辅助进程退出、格式异常均不覆盖原文。
请求为单独工作线程，不使用按键候选线程；同一选区最多一个请求。
