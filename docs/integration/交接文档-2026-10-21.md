## 4. 已完成的具体工作与证据边界

### 4.1 表达与回写

- 表达意图使用独立 `POST /expression`，直接调用 Provider；不进入 Agent loop，不挂工具、MCP、hooks 或工作区，并限制输入、输出和运行时间。OpenAPI、路由契约及 TS 类型同步。
- 非表达请求导向 Agent 界面，不生成可插入的“Agent 回复”候选。
- `replace_selection` 在写入的同一编辑会话复核上下文、焦点/敏感状态和选区摘要；不确定时拒绝写入。
- 草稿修改、重复确认、重复执行、取消/过期、旧预览失效、重试与迟到结果有定向回归；每项范围见工程文档，不能扩称所有真实应用均通过。
- 首次记事本 DeepSeek 回写是历史验收；配套记录包含 TSF 提权注册、.NET SDK 10.0.302、NuGet 回退目录和 Python ZIP 正斜杠打包修复，见工程文档 §5.1。

### 4.2 配对与只读来源链路

- 已实现本人确认窗口、私有凭据保护/持久化及失败回滚、C++ 请求证明、跨语言认证管道、产品网关强制认证。
- 身份绑定包含内核取得的进程 PID、创建时间、EXE 摘要及用户/登录会话，防止同 EXE 第二实例直接继承授权；撤销、到期、防重放等有对应回归。
- 真实证据：Core → 已安装连接器 1.3.2 → 本人确认的网关 → 来源已验证 Daemon → DeepSeek `deepseek-chat` 返回 `Hello`，预览选区摘要/上下文匹配。该运行之后清理了本次凭据、恢复设置并关闭测试服务，不是常驻部署。
- 表达来源凭证绑定精确请求/最终提示摘要、任务与进程身份，限制为 `expression_only`；上游 `origin_verified=true` 才接受。签发密钥独立、仅经进程环境注入。
- **限制**：当前为开发宿主登记，不是签名安装器证明；应用名、选区、context 仍是连接器声明。旧桌面无凭证兼容路径保留 bearer 和无工具约束，不得据此获得执行权限。

### 4.3 策略、审批和网络边界修复

- 工具调用检查全部涉及的权限维度，不再只检查单一类别；MCP/未知工具在不能证明范围时保守拒绝。拒绝产生明确失败结果事件。
- 审批模型对副作用的 ALLOW 仅作建议，仍须进入实际 Approver，不能由模型自授权限；生产 Agent→ToolHost 路径有合成正负例。
- `POST /subagent/run` 无逐动作审批通道的副作用模式返回 403，Web 对应选项禁用；其他 CLI/工作流入口仍须统一复核。
- 修复 IPv6 字面私网地址解析绕过；真实本地 socket 回归证明 `::1` 与 IPv4 映射回环地址在连接前被拒绝，不代表全部 SSRF 面已消除。
- 无目的地址执行 broker 时，精确域名 AllowList 返回 Unsupported，不能转换成宽泛 Internet/LAN 权限后冒称已限制目标域名。

### 4.4 最新 Windows 执行器修复与构建

- AppContainer API 改为正确 Userenv DLL/HRESULT 与 SID 释放；每次建立私有临时配置，进程结束后删除，不共享任务身份、不授予真实工作区 ACL。
- 修复管道读端转交后原容器仍关闭、写端重复关闭造成的句柄所有权错误。
- 修正 JobOnly 被枚举比较错误送入 Low IL 路径；保留 JobOnly 资源/生命周期语义，明确请求 LowIntegrity 才使用该令牌。
- 工作进程仅继承明确 Windows/工具链环境名单和受信宿主显式覆盖；真实合成子进程验证未声明值不被继承。不覆盖 SDK 所有其他直接启动/MCP 路径。
- 严格 AppContainer 子进程已能返回合成输出，不使用普通进程回退。**只证明当次输出链路，不证明令牌、文件/网络、IPC、子进程边界的完整隔离。**
- 先前 LowBoxConsoleEnabled 注册表试验因代码修复后不再需要而取消；后来用户同意临时验证，但没有执行，也没有改注册表。不要重新把它当作待办或扩展授权。
