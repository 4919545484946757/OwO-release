# 紧凑搭配证据与混拼词尾召回（第一阶段）

目标：`xiufuleisiwt` 能产生“修复类似问题”，且不写入该拼音的特定答案。

## 数据来源与索引

本阶段没有下载或分发授权未确认的 CCA 数据，也没有加载 LTP。
搭配证据来自当前已启用词典：两个真实多字词的完整读音与连接正文，
在词典中还有对应的完整短语时，记录一条正证据；不存在则保持中性。
这不是从大语料抽取的频率/依存搭配库，而是可以先行验证的词典派生原型。

索引是请求内只读证据查询缓存：文本及读音写入连续字节池，排序记录仅存
偏移、长度和小整数分数，二分查询；缓存命中与未命中结果，最多 256 条记录。
不在启动时扫描或展开全量词典，不新增安装数据包或持久用户数据。
词典/配置更换后的新请求自动使用新证据。

## 生成阶段

- 仅在混拼词链连接时使用证据；当前只考虑两个至少双音节、合计不超过四音节的词。
- 有证据每次加 1000 分，整条搜索状态累计不超过 2000；不替代基础词频和语言模型。
- 原输入已完整拼出的前段后，若尾部为 2–4 个声母，额外查询词典中的整词匹配。
  每个后缀最多取 64 个词条，按完整读音去重后最多保留 32 条候选路径。
  这些路径与已有路径共同按词典覆盖/频率评分，仍受原每类至多 16 条辅助路径
  评估上限约束，不提高 Beam。纯声母前段、纠错前段不使用该回退。
- 该召回修复了问题的关键前置条件：泛化补全不能先把预算都花在 w/ta 等排列上，
  必须让词典支持的 wen/ti 进入比较。搭配加分不能替代缺失路径的召回。
- 保留精确源片段及消费长度；不跨越尾部的手动撇号边界。

基础候选与模型排序都保留正常配额、分区、近似去重及用户学习规则。
同一组合态第一次确定的纠错回退决策随缓存保持，避免扩大搜索预算后又混入
新的纠错族，导致关闭分区时分页与展开不一致。

## 当前结果与边界

真实词典下“修复／处理／解决／发现类似问题”的混拼尾部样例以及完整拼音对照，
均能生成目标，基础模式和智能排序首选命中。未导入用户学习，也未增加特定答案。
页长 5/7/9、分区开关分别回放；隔离报告在
`build/sentence-page-layout/reports/collocation-*`，`trial`/`wide` 是实验记录。

后续若接入授权明确的独立搭配数据，应另建离线编译资源和版本化加载器，
不能将当前请求内证据缓存宣称为已完成的大规模离线搭配库。

12 项候选/词链/预算/复用/用户词/分区/快照/展开/符号相关 CTest 通过；
既有 78 条控制样例目标排名未变，运行错误与分页/展开差异为零。
关闭分区时以 `collocation-stable-off-*` 为最终一致性结果；早期
`collocation-final-*-off` 暴露的纠错回退不稳定问题已修复。未执行全量自检。
