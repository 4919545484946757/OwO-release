05 / API & DATA

API 与数据设计

当前为本机输入法，不提供 HTTP 服务或关系型数据库。此处的 API 指进程间契约和插件服务；文件布局是实际数据模型。

接口地图

边界消息 / 字段约束与失败行为源码
① ⇄ ②candidate_request/response、candidate_update_request/response、candidate_committed；request_id、context_generation、input、page、candidates、candidate_consumed本机命名管道；严格解码；旧请求和旧焦点结果不得覆盖新快照。内部 JSON，未冻结为公共 API。include/owo/protocol/messages.h
② ⇄ ③rank_request/response；请求 ID、超时、输入、上下文、候选模型协议 v2；错误、超时退回基础排序。include/owo/model/model_protocol.h
② ⇄ ④hello/invoke/cancel/shutdown；插件 ID、服务名、请求 ID、payload插件协议 v1；单条 payload 上限 256 KiB；按清单和实际授权检查。include/owo/plugin/plugin_protocol.h
④ ⇄ ⑧session_id、action、应用上下文、结构化命令 IDAgent 协议 v3，兼容 v2；脱敏、限长、会话匹配；消息文本绝不解析成控制命令。include/owo/agent/agent_protocol.h
输入方案扩展方案 ID、输入、页码、候选 ID、consumed_ranges实验接口；范围按原始 UTF-8 半开字节区间，宿主决定上屏。include/owo/engine/input_method_provider.h

本地数据模型

配置

%LOCALAPPDATA%\OwO\InputMethod\config\owo.conf。配置模块负责校验、保存与监视；导入先确认并备份。

词典

.owolx 为紧凑只读基础词典；独立导入词库有启停、补码和管理状态。停用候选来源不等于删除启动文件。

用户学习

data\user-frequency.owuf 与 .bak；Core 串行修改，版本代数防并发覆盖，导出不含上下文历史。

插件

每个插件有清单、专属 settings.json 和独立授权记录；配置不等于权限。

模型

本地 libime 资源；为可选排序依赖，不是用户词库的唯一来源。

日志

位于本地数据目录下；诊断日志不得泄露密码或完整敏感输入。

对外接入请以插件开发文档和输入方案文档为准；内部 IPC 的字段和二进制布局不承诺跨版本兼容。
