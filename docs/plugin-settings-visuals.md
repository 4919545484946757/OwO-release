# 插件页视觉参数

已安装插件项及在线插件项均增加圆角左侧边框，不改变原卡片内容的布局或点击区域。
颜色匹配词库卡片现有叠加边框：`ARGB(120,0,0,0)`，即 `#78000000`。
左侧厚度为 3，圆角半径为 8。

插件管理器（已安装、下载插件、恢复与维护）及插件配置页使用用户提供的 `拼图轮廓.svg`，保留原始路径和描边形状。
浅色主题为原黑色描边，深色主题仅将描边换为白色；高对比度隐藏装饰。
图片固定在配置页视口后方，不随表单滚动，不拦截鼠标或辅助技术焦点，
旋转和负偏移产生的溢出由页面裁剪，不覆盖标题、导航或底栏。
贴图的层级显式低于滚动内容；插件选项及管理卡片增加与页面底色相同的不透明底层，
防止默认半透明卡片透出贴图，保留原卡片自身的填充与边框。

| 参数 | 数值 |
| --- | --- |
| 贴图显示强度（Opacity） | 0.2（20%，即透光率 80%） |
| 显示尺寸 | 480 × 480 |
| 锚点 | 插件管理器 / 配置页视口右上角 |
| 右边距 / 上边距 | −88 / −104（向右外移 88、向上外移 104） |
| 旋转角度 | −18°（逆时针） |
| 旋转中心 | 图像中心 `(0.5, 0.5)` |

位置和尺寸使用 XAML 逻辑单位，实际像素随 DPI/窗口缩放变化。
参数位于 `MainPage.xaml` 的 `PluginPuzzleBackground` 及 `PluginPuzzleOpacity` 资源。
资产位于 `apps/settings_center/Assets/Decor`，由项目复制到构建/发布目录。

定向检查：`powershell -NoProfile -File tests/settings_center/PluginVisualContractTests.ps1`。
