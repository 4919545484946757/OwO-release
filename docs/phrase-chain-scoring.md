# 完整词链与重叠词条计分

`zidongzhankai` 正确分割为 `zi/dong/zhan/kai`，词典同时含“自动”与
“展开”。原问题发生在候选连贯性评分，而非缺词或拼音纠错。

“自动站开”已按“自动＋站开”取得完整词链评分，却又因低频“自动站”
跨过该分词边界获得 24,000 分固定奖励。该重叠证据不是独立证据，
反而让它超越更高频的“自动＋展开”，后者被长句候选限额隐藏。

现在在现有短语匹配循环内同步记录是否存在完整、不重叠的多字词链：
如果存在，就不再授予额外的重叠词桥奖励。仍需重叠短语覆盖孤立单字
的输入（如“按优先度”）保留原词桥逻辑。词频、用户明确学习、整词
优先和长句数量上限不变；无词语白名单，不扩大搜索预算或重复查词。

  修复后前者降为 23,504 分，后者不变，并成为首页及展开列表首候选。
