# 分段上屏学习的组合态隔离

## 根因

TSF 的分段学习文本、源编码与前文曾独立保存在三个字符串中。
`clear_composition()` 清除了候选与拼音，却没有清除这三个字符串；
最终分段上屏也只发送合成反馈，没有消费旧链。因此，后续独立输入会被
接到已结束或已取消的组合态后面，出现无关长词，真正的新词则没有独立
编码映射。单字的学习计数仍可能正常增长，不能因此判定整词学习正常。

## 处理

- 用 `CompositionLearningChain` 统一管理文本、编码与初始上下文。
- 每个成功的部分上屏加入当前链；最终上屏消费结果并立即清空。
- 所有清除组合态路径同步清空学习链，包括取消、失焦清理、删除至空、
  原文提交、切换输入方案及 Agent 组合态替换。
- 提交成功前只使用快照，不改变原状态；失败不增加学习记录。
- 暂存候选与立即上屏使用相同的组合边界，原文字母不加入中文词映射，
  仅提交原文时也不重复计数已学习的单个前缀。标点结束当前学习链。
- 不根据长词尾部猜测并自动拆分历史词条，不批量删除用户数据。
  对用户明确指出、确认有效的映射可通过现有事务词库接口单独恢复。

## 回归

`owo.tsf.composition_learning` 覆盖连续两次独立组合、结束后再次输入、
清理/取消边界、成功提交快照、正确的文本与源编码，以及新用户词的
完整和不完整拼音召回。姓名仅作为测试夹具，生产代码不含特定姓名、
拼音或异常长词的特判。

TSF 位于应用进程内；部署使用不同文件名旁置 DLL，避免覆盖已加载文件。
更新注册后，已有应用仍可能持有旧模块，应关闭并重新打开测试应用。
