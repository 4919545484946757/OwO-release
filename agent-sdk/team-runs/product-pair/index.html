把注意力，收回这一件事

FocusFlow 是一个极简专注计时器：设定一段时间，按下开始，剩下的交给倒计时。 到点会亮起横幅、响一声提示音，并在浏览器标题里告诉你「该休息了」。

  • 开始 / 暂停 / 重置一键切换，随时接住被打断的节奏
  • 1–90 分钟自由拖动，内置 15 / 25 / 45 / 60 分钟常用预设
  • 完成后横幅 + 提示音 + 页面标题三重提醒，不会错过

为「不想被打断」而设计

专注只做一件事

没有账号、没有通知流、没有排行榜。页面只保留倒计时和你此刻要做的事。

节奏由你决定

1–90 分钟任意调节，暂停后可以随时继续；同一段专注里反复调整也不会丢状态。

完成会被看见

到点后横幅提示、短促提示音和标题变更同时出现，即使切到别的标签页也能察觉。

三步进入专注

  1. 设定时长拖动滑块或点选预设，决定这一轮要专注多久。
  2. 按下开始倒计时开始，圆环随时长收缩；需要中断就点暂停。
  3. 收下提示完成横幅出现，喝口水，再点「再来一轮」继续。
