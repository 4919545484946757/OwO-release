Ship tool-using agents without rebuilding the plumbing.

OwO Agent SDK bundles typed tool calling, retries, streaming and record-and-replay tests into one small dependency — so your team ships agent features instead of agent infrastructure.

Start in 3 minutes See what's included
  • ✓ No account required
  • ✓ 12 kB min+gzip core

agent.mjs

import { Agent, tool } from "owo-agent-sdk";

const weather = tool({
  name: "get_weather",
  description: "Current weather for a city",
  schema: { city: "string" },
  run: ({ city }) => fetchWeather(city),
});

const agent = new Agent({
  model: "owo-fast",
  tools: [weather],
});

const reply = await agent.run("Do I need a jacket in Oslo?");

Features

Everything an agent needs, nothing it doesn't

Each primitive is independently usable and covered by the same public test suite you run locally.

  • ⚙️

    Typed tool calling

    Declare a schema once and get argument validation, structured errors and automatic JSON repair on every call.

  • 🔁

    Retries you can reason about

    Idempotency keys, jittered backoff and a hard budget cap keep failures cheap and observable.

  • 🎥

    Record & replay tests

    Capture a real transcript once, then replay it in CI with zero network calls, zero flakiness.

  • 🌊

    Streaming by default

    Token deltas, tool events and partial objects arrive on one async iterator you can forward to any transport.

  • 🔌

    Bring your own model

    Adapters for hosted APIs, local runtimes and your own gateway. Swap providers with one config line.

  • 🛡️

    Guardrails built in

    Budget limits, redaction hooks and approval gates for destructive tools ship as first-party plugins.

Quickstart

Three commands to a running agent

No config file, no dashboard. The CLI writes a working example and a matching test for you.

  1. 1 Install

    npm install owo-agent-sdk

  2. 2 Scaffold

    npx owo-agent init my-agent

  3. 3 Verify

    npm test

The generated test suite uses node:test and replays fixtures, so it runs offline in under a second.

FAQ

Questions teams ask before adopting

Do I need an API key to evaluate it?

No. The scaffold ships with a replay fixture, so npm test works offline. Add a key only when you point the agent at a live model.

Which runtimes are supported?

Node 18 and newer, Deno, Bun and edge workers that expose standard fetch and WebStreams.

How are tool arguments validated?

Each tool declares a schema. Invalid arguments never reach your function; they surface as a structured error the model can retry against.

Can I self-host everything?

Yes. The SDK is client-side code, and the Enterprise tier ships the gateway and explorer as containers you run in your own network.
