Developer SDK · agent 能力层

少写代码，构建可编排的 agent OwO Agent SDK 让开发者用少量代码构建可编排、可观测的 agent 能力。

用声明式工具定义替代手写调度：注册工具、编排步骤、拿到结构化日志。

开始接入 阅读文档（占位）

核心能力

四条能力覆盖从工具接入到线上观测的完整链路；每条都可以单独使用。

  • 声明式定义工具

    用一个对象描述参数与返回值，SDK 负责校验、类型映射与错误包装。

  • 可编排的执行流程

    把多个工具串成有顺序的步骤，支持条件分支与失败重试的显式配置。

  • 逐次调用的可观测性

    每次运行输出结构化事件：输入、工具、耗时、结果与失败原因。

  • 可插拔的运行时适配

    自定义传输层与环境绑定，便于在本地、CI 或服务端复用同一套定义。

三步接入

以下路径在本地即可完成，不依赖任何外部服务即可跑通最小示例。

  1. 安装 SDK

    在项目根目录安装包本体；无构建步骤，无额外运行时依赖。

    npm install owo-agent-sdk

  2. 初始化客户端

    创建一个客户端实例，注册你需要的工具定义。

    import { createClient } from "owo-agent-sdk";

const client = createClient({ name: "demo" });

  3. 运行一次流程

    调用工具并读取结构化结果与事件日志。

    const run = await client.run("lookup", { query: "agent" });
console.log(run.events, run.result);

常见问题

OwO Agent SDK 是什么？

一个面向开发者的 agent 能力 SDK：用它定义工具、编排执行步骤，并拿到每次调用的结构化事件。

接入需要改动现有技术栈吗？

不需要。SDK 是独立包，通过函数调用接入；你可以只使用工具定义部分，不启用流程编排。

它包含托管服务或账号体系吗？

不包含。SDK 只提供本地运行时的能力与可观测事件；模型与传输由你自行配置。

如何调试一次失败的调用？

读取运行结果中的事件列表，定位失败步骤的输入与错误信息，再针对该工具补充校验。
