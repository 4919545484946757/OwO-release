# WorkSwarm · 12s 产品宣传 HTML 动态分镜（animatic）

> **交付形态**：可在浏览器直接打开、按镜头时间线自动播放的 HTML/CSS/JS 动态分镜（motion storyboard）。
> **不产出、不伪造任何视频文件**：目录内无 `.mp4/.webm/.gif`，无 `<video>` 指向不存在文件，无录制/转码脚本，页面无“下载视频”入口。若需要 MP4，须由独立录屏环节对本页面另行录制。
> **零外部依赖**：无 CDN、无网络字体、无第三方图标库（箭头/勾号/LOGO 全部内联 SVG），断网 `file://` 双击即可播放。
> **唯一权威分镜源**：`docs/storyboard.md`（director v1）。毫秒时间点未改动，呈现层偏差见 §6。

## 2. 时间线（毫秒严格对齐 `docs/storyboard.md`）

总时长 **12000ms**，6 镜。所有 CSS 动画 `animation-duration: var(--total)`（12000ms）、`iteration-count: infinite`，因此单一根时间轴可整体调速与精确 seek；百分比换算 `pct = ms / 12000 × 100`。

## 3. 交互与控制

| 控件 | 行为 |
| --- | --- |
| **播放 / 暂停** 按钮 | 切换播放态；图标在 ▶ / ❚❚ 间切换，同步 `aria-label` 与 `aria-pressed`；暂停后画面定格在当帧（不是复位） |
| **重播** 按钮 | 归零 → 移除 `playing/paused/static` 并强制重排以重建全部 CSS 动画 → 立即播放，曲线从 0 开始 |
| **进度条**（range，0–12000，step 10） | 拖动即定位当帧；轨道填充由 `--progress` 驱动；`aria-valuetext` 朗读秒数 |
| **镜头跳转按钮** S01–S06 | 跳到 0 / 1500 / 4000 / 6500 / 8000 / 10500ms；当前镜按钮高亮 `is-active` |
| **键盘** | `Space` 播放/暂停 · `R` 重播 · `1`–`6` 跳镜 · `G` 显隐安全区（左右 96px / 上下 72px 虚线框） |
| **URL 参数** | `?t=8000`（毫秒）→ 进入单帧态：暂停并显示该毫秒对应镜头的可视终态，用于逐镜截图验收 |
| **HUD（舞台内）** | 左上：`S0x` + 镜头名 + 时间段；右上：`当前秒 / 12.00s`；底部安全区居中字幕（40px/600，行高 1.4，主 + 副最多两行） |

**时间轴实现**：控制器内维护三张表——`SHOTS`（镜号/名称/起止）、`SUBS`（6 条字幕时间窗）、`SUB_SUB`（S05 副字幕 8900–10400ms），数值逐项抄自分镜表 §1 与 §5。`requestAnimationFrame` 用 `performance.now()` 差值推进虚拟时间，再通过 `stage.getAnimations({subtree:true})` 把每条 CSS 动画的 `currentTime` 同步为 `虚拟时间 − 该动画 animation-delay`。因此暂停、拖动、跳镜、`?t=` 单帧时，**画面帧、HUD 时间、字幕时间窗三者严格同源**，不会出现“时间走了画面不动”或错位。

## 4. 自适应与可访问性

- **舞台缩放**：`.stage` 固定逻辑 1920×1080，`transform: scale(var(--stage-scale))`；`fitStage()` 取 `min(容器宽/1920, 容器高/1080)`，`ResizeObserver` + `resize` + `orientationchange` 三重触发。CSS 侧另有 `width: min(1920px, 100%, (100vh - 180px) * 16/9)` + `aspect-ratio: 16/9` 兜底，即使 JS 未执行也是正确 16:9 画幅。
- **移动端**：≤900px 时 HUD 缩至 13px 胶囊、隐藏镜头跳转按钮、控制条换行、字幕降到 22px/16px；≤560px 按钮只留图标、`readout` 独占一行；`viewport-fit=cover` 适配刘海屏；触屏 `@media (hover: none)` 关闭 hover 视觉残留。
- **可访问性**：正文 `#FFFFFF` / `#A9B4CC` on `#0B1020`，对比度 ≥ 4.5:1；每个镜头 `section` 带 `aria-label`（镜号 + 名称 + 时间段）；按钮有 `aria-label` / `aria-pressed` / `:focus-visible` 焦点环；`prefers-reduced-motion: reduce` 时去除位移/缩放/光带/擦除，仅保留透明度变化，勾号与连线直接呈现终态。
- **性能**：动画只使用 `transform` 与 `opacity`；`backdrop-filter` 元素共 8 个（7 张窗口 + 1 张提示卡）；无逐帧大面积 `box-shadow` 动画。

## 6. 偏差项与已知限制（如实说明）

### 偏差项（毫秒时间点一律未改，以下是呈现层取舍）

| 项 | 分镜源 | 实现 | 原因 |
| --- | --- | --- | --- |
| 文件拆分 | 建议 `index.html` 单文件 | `index.html` + `styles.css` + `runtime.css` | 任务书要求交付 `animatic/styles.css`；`runtime.css` 只放运行时补丁，不引入外部依赖 |
| S01 标题字号 | 未指定 | 104px / 800 / 字距 .04em | 安全区 1728px 宽内 10 字标题单行可容 |
| S02 红框高亮卡 | “红边框高亮卡片压顶” | 额外一张 660×300 居中提示卡，承载「重复劳动 / 信息割裂」两个标签；7 张底卡仍为 420×260 | 需要承载两个标签文案 |
| S02 抖动 | `steps(2)`×3 | 用 3 段 ±2px 位移关键帧模拟阶梯抖动 | `scale+rotate` 已占用 transform，`steps()` 与并列变换叠加易抖动，改用显式阶梯更稳 |
| S05 分割线 | “细分割线横向展开” | 卖点下方 760px 渐变细线 `scaleX 0→1`（8400–8900ms） | 视觉更聚拢，时间窗未变 |
| S05 扩散光环 | 周期 1200ms、`opacity .35→0` | 8900–10200ms 内 2 轮，两层环由 `animation-delay: 600ms` 错开 | 严格落在 1200ms 周期内，未越界 |
| S02 字幕叠放 | “同屏最多 1 行主字幕” | `信息散落在 7 个窗口里` 与 `每个动作，都在重复搬运` 有 200ms 重叠，实现为同位置交替显示（后者仍在原时间窗出现） | 忠实保留源表时间窗 |

### 限制

1. **没有 MP4**：本轮不产出任何视频/序列帧文件，仓库内只有可播放的 HTML 动画。要 MP4 必须由外部录屏工具录制本页面（`?t=` 可辅助逐帧定位）。
2. **没有音频**：音效点仅在文档与分镜表中标注，页面不播放、不嵌入音频。
3. **字体**：禁止联网，中文用系统回退栈（Noto Sans SC / 思源黑体 / PingFang SC / 微软雅黑），不同系统字形宽度略有差异，长文案（S05 主字幕 22 字、S01 标题 10 字）在缺字体环境下可能略宽/略窄，未做逐像素锁定。
4. **浏览器能力依赖**：精确 seek 依赖 `Element.getAnimations`（Chrome 84+ / Safari 13.1+ / Firefox 75+）；不支持时会退化为“CSS 动画自然播放 + 控件只能重播/暂停”，播放/暂停/重播仍可用。`backdrop-filter` 在不支持的浏览器退化为半透明纯色卡片，不报错。
5. **运行时未实测**：见 §5 末段，本环境无浏览器与命令执行能力，暂停/拖动/`?t=` 的一致性与跨浏览器表现未验证。

## 7. 交接给下游

- **录屏出片**：先按 §5 六点校对，再用 12.0s 整段播放录制（页面无限循环，务必按 12.0s 截断，避免多录一轮）。
- **继续调参**：动效参数集中在 `animatic/styles.css` 的 `@keyframes` 段（每镜一组，注释标毫秒锚点）；镜头/字幕时间表集中在 `index.html` 内联脚本的 `SHOTS` / `SUBS` / `SUB_SUB` 三个数组，改数值即可，不必动结构类名。
- **增删镜头**：新增 `<section class="shot" data-shot="S07">` → 加 `@keyframes shot-on-7` → `SHOTS` 表补一条 → 同步 `TOTAL` 常量、`scrub` 的 `max`、`styles.css` 里的 `--total`（三处必须一致）。
- **禁止事项（沿用分镜源）**：不得引入需联网资源；不得伪造 MP4 / 嵌入不存在的 `<video>` / 调用录制 API / 放置“下载视频”入口。
