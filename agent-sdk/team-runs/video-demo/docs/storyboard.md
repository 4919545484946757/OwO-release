# 分镜脚本（Storyboard）— 12 秒产品宣传 HTML 动态分镜

> 交付边界声明（必读）
> - 本工作流**只交付 HTML/CSS/JS 动态分镜（motion storyboard）**，目标是可直接在浏览器打开、按时间轴自动播放的动画 Demo。
> - **不产出、不伪造 MP4**：不生成视频文件、不写 ffmpeg/录制脚本、不在文档或代码中声称"已输出 mp4"。
> - 下游 animator 依据本文件的镜头序号、时长、画面主体、动作、字幕、转场与节奏点，用 HTML/CSS/JS 逐镜实现；总时长 12s，时间轴以毫秒为单位严格对齐。
> - 画布规格：1920×1080（16:9），安全区左右各 96px、上下各 72px；统一使用 1 个根时间轴 + 逐镜 `@keyframes`，方便整体调速与截图验收。
> - 交付物形态：`docs/storyboard.md`（本文件）+ 由 animator 产出的 `index.html`（动态分镜播放器）+ 引用本文件的镜头数据 JSON。

## 2. 逐镜分镜

### S01 开场钩子｜0.0s–1.5s（1500ms）

- **画面主体**：全屏深空蓝黑底（径向渐变 `#0B1020` → `#000000`），中心 1 个直径 8px 的白色光点，光点外围 1 圈电光蓝辉光。
- **动作（时间轴）**：
  - 0–150ms：白闪（全屏 `#FFFFFF` 透明度 0.18 → 0），模拟开场闪光。
  - 0–400ms：光点从 `scale(0.2)` 弹到 `scale(1)`，透明度 0 → 1。
  - 300–900ms：光点周围扩散 3 圈同心圆环（`scale 1 → 4`，透明度 0.6 → 0），错开 120ms。
  - 600–1200ms：主标题文字 `智能工作流，一步到位` 逐字上浮（每字延迟 40ms，y 轴 24px → 0，透明度 0 → 1）。
  - 1200–1500ms：光点扩散成横向光带，亮度峰值后整体透明度降至 0。
- **字幕/旁白**：字幕 `— 一步到位，从想法到交付 —`（底部居中，进 600ms 出现，1200ms 淡出）；旁白建议："把想法，直接变成交付。"
- **转场（出）**：光点扩散淡出（`opacity 1→0`，200ms，配合 S02 背景继续保留）。
- **参考风格**：发布会开场闪光 + 逐字上浮标题；文字描边不加阴影，仅用极轻的外发光（`text-shadow: 0 0 24px rgba(79,124,255,.35)`）。

### S02 痛点呈现｜1.5s–4.0s（2500ms）

- **画面主体**：背景延续深色，画布中央出现 7 张"杂乱窗口卡片"（尺寸 420×260，圆角 12px，玻璃拟态：`backdrop-filter: blur(8px)` + 1px 描边 `rgba(255,255,255,.12)`），分别代表散落的聊天、表格、待办、邮件、文档等任务，卡片随机旋转 -8°~+8°。
- **动作（时间轴）**：
  - 1500–2100ms：7 张卡片从画布四周飞入并堆叠（每张延迟 80ms，`translate` 由外向内 + `scale 1.15→1` + `opacity 0→1`）。
  - 2100–2600ms：堆叠继续加压，整体轻微抖动（±2px，`steps(2)` 抖动 3 次），细节文字（占位灰条）出现"乱码闪烁"（透明度 0.4↔0.9）。
  - 2600–3200ms：卡片群整体轻微下沉（`translateY 0→-8px→0`），营造窒息感。
  - 3200–3700ms：一张高亮红边框卡片压在最上层，标签 `重复劳动 / 信息割裂`。
  - 3700–4000ms：所有卡片向中心塌缩（`scale 1→0.92`，`opacity 1→0.85`），准备被下一镜"擦掉"。
- **字幕/旁白**：
  - 1800ms 起：`信息散落在 7 个窗口里`；
  - 2900ms 起：`每个动作，都在重复搬运`；
  - 旁白建议："每天，你在窗口之间来回搬运同一件事。"
- **转场（出）**：卡片塌缩 + 横向擦除（一条白色 8% 透明度竖条从左向右扫过，300ms，扫过处卡片透明度归零）。
- **参考风格**：UI 卡片拟真 + 轻混乱感；抖动幅度必须小，避免成为"故障风"。

### S03 产品登场｜4.0s–6.5s（2500ms）

- **画面主体**：画布中央 1 张主产品界面卡片（1280×760，圆角 20px，深色玻璃 + 顶部 3 个窗口圆点 + 内嵌左侧导航与右侧内容区），卡片下方 1 层柔和投影与地面反光。
- **动作（时间轴）**：
  - 4000–4600ms：主卡片从 `scale 0.86 / opacity 0` 聚光登场至 `scale 1 / opacity 1`，同时背景径向高光（电光蓝）从中心亮起。
  - 4300–4900ms：一条对角线光带（白色 12% 透明）从左下扫到右上，扫过卡片表面。
  - 4600–5400ms：卡片整体缓慢推镜（`scale 1 → 1.06`，线性），营造"推进感"。
  - 5400–6000ms：卡片内左侧导航 5 个条目依次点亮（第 1 项常亮，其余 4 项延迟 100ms，`opacity 0.4→1`）。
  - 6000–6500ms：右侧内容区网格（3×2 卡片）从下往上依次浮现（每块延迟 90ms，`translateY 20px→0`）。
- **字幕/旁白**：4200ms 起 `一个入口，接管全部工作`；旁白建议："现在，一切都收进同一个工作台。"
- **转场（出）**：推镜后竖向滑出（整卡片 `translateY 0 → -24px` + 下一镜元素自下方进入，总 250ms）。
- **参考风格**：产品静物打光式的高光扫过 + 玻璃拟态；推镜速度必须线性、缓慢（1.06 倍封顶，避免眩晕）。

### S04 核心功能演示｜6.5s–8.0s（1500ms）

- **画面主体**：同一主卡片（保持可见，位置略上移 24px），右侧内容区聚焦 3 个功能要素：① 任务卡片队列、② 自动化流程连线、③ 结果状态徽标 `已完成`。
- **动作（时间轴）**：
  - 6500–7000ms：要素① 任务卡片队列被高亮框选中（金色/电光蓝描边 2px 呼吸一次），队列中 3 张卡片向内收拢对齐。
  - 7000–7500ms：要素② 出现连接线段（`stroke-dashoffset` 由长到 0，400ms 绘制完成），线上有 2 个光点沿线运动。
  - 7500–8000ms：要素③ 状态徽标从 `处理中`（灰色）翻转为 `已完成`（绿色 `#22C55E`），伴随一次 1.08 倍弹跳与勾号对勾描绘（`stroke-dashoffset` 动画 200ms）。
- **字幕/旁白**：6600ms 起 `拆解 → 执行 → 交付`；旁白建议："它自己拆任务，自己跑流程，自己给你结果。"
- **转场（出）**：要素③ 完成后整体 `slide up`（卡片 `translateY 0 → -40px` + 透明度 0.9），为 CTA 让出中心位置，200ms。
- **参考风格**：极简 UI 动效演示，元素依次点亮、严格 500ms 一拍，成为节奏最密集的一段。

### S05 CTA 高潮｜8.0s–10.5s（2500ms）

- **画面主体**：画布中心 CTA 按钮（尺寸 520×104，圆角 52px，填充电光蓝→橙红渐变 `#4F7CFF → #FF5A3C`，按钮文字 `立即开始，免费试用`，字号 36px/字重 700，右侧 1 个箭头图标）；按钮下方 3 个卖点标签横排：`无需部署` `3 分钟上手` `数据自持`。
- **动作（时间轴）**：
  - 8000–8400ms：CTA 按钮从 `scale 0.7 / opacity 0` 弹入至 `scale 1 / opacity 1`（`cubic-bezier(.16,1,.3,1)` 回弹）；同时中心背景亮起橙红径向光。
  - 8400–8900ms：按钮下方 3 个卖点标签依次上浮（每项延迟 120ms），并出现一条细分割线横向展开。
  - 8900–10200ms：CTA 进入呼吸脉冲循环（`scale 1 ↔ 1.05`，周期 800ms，`ease-in-out`），按钮外圈有 2 层扩散光环（周期 1200ms，透明度 0.35 → 0）；箭头图标每周期右移 6px。
  - 10200–10500ms：脉冲收敛为静止 1.0 倍，透明度保持 1。
- **字幕/旁白**：8300ms 起 `现在开始，把 12 秒变成 12 小时的效率`（主字幕）；8900ms 起副字幕 `点击下方按钮，30 秒完成首次体验`。旁白建议："现在，就交给它。"
- **转场（出）**：呼吸脉冲结束后整体轻微下压（`translateY 0 → 8px`）+ 透明度 1 → 0.92，100ms，切向落版。
- **参考风格**：强对比 CTA 强调色（橙红）+ 扩散光环，是整片唯一暖色段落，务必与前置冷色形成反差。

### S06 收尾落版｜10.5s–12.0s（1500ms）

- **画面主体**：纯深色底，中央 LOGO 标记（圆角方形 96×96，电光蓝底 + 白色符号）+ 品牌名 `WorkSwarm`（字号 56px/字重 800）+ 下方 URL `your-domain.com`（字号 28px，`#A9B4CC`）。
- **动作（时间轴）**：
  - 10500–10900ms：LOGO 标记从 `scale 0.8 / rotate(-8deg) / opacity 0` 落版至 `scale 1 / rotate(0) / opacity 1`。
  - 10700–11100ms：品牌名逐字上浮（每字 40ms）。
  - 11000–11400ms：URL 淡入（`opacity 0→1`，`translateY 12px→0`）。
  - 11400–12000ms：整体定格 400ms，随后整体 `opacity 1→0` 在 200ms 内淡出至纯黑，最后 400ms 保持纯黑（等同于播放结束）。
- **字幕/旁白**：无字幕；旁白建议："WorkSwarm，让每一次交付都自动发生。"
- **转场（出）**：整体淡出至纯黑（fade out），为循环播放留出无跳点的收尾。
- **参考风格**：品牌落版 + 简洁留白，与 S01 的光点构图形成首尾呼应。

## 3. 视觉与动效规范（animator 实现约束）

1. **结构建议**：`index.html` 单文件；一个 `<div class="stage">`（1920×1080，用 `transform: scale()` 自适应视口），内部 6 个 `<section class="shot" data-shot="S01">`，通过根时间轴统一控制 `display/opacity`。
2. **时间轴驱动**：推荐用一份 `const TIMELINE = [...]` 数据（镜号、start、duration、keyframes 名）驱动 CSS 动画 `animation-delay` 与 `animation-duration`，保证与本文档毫秒数一致；页面加载后自动播放，并支持 `?t=8000` 之类的参数直接跳到某一时刻便于截图验收。
3. **禁止项**：不得引入需要联网加载的资源（字体请用 `font-family` 回退栈，图标用内联 SVG）；不得伪造 MP4、不得嵌入 `<video>` 指向不存在的文件、不得调用录制 API。
4. **性能**：仅动画 `transform` 与 `opacity`；`backdrop-filter` 卡片数量 ≤ 8；避免大面积 `box-shadow` 逐帧变化。
5. **可访问性**：所有文字对比度 ≥ 4.5:1；提供 `prefers-reduced-motion: reduce` 降级（跳过位移，仅保留透明度淡入淡出）。
6. **验收截图点**：0.4s（S01 标题）、2.2s（S02 堆叠峰值）、5.2s（S03 推镜中）、7.8s（S04 已完成徽标）、8.8s（S05 CTA 脉冲）、11.6s（S06 落版）。

## 6. 音效建议点（仅标注，不产出音频）

- 0.0s 白闪 + 低频"咚"；0.4s 光点弹入短促"叮"。
- 1.5–3.7s 卡片飞入每张一个轻"啪"（音量递减），3.7s 一次闷响。
- 4.0s 聚光"呼"声 + 4.3s 光带扫过的细碎高频。
- 6.5/7.0/7.5s 三下节奏点（与点亮同步）；7.8s 成功的双音上行。
- 8.0s CTA 出现重拍 + 高频闪烁；8.9s 起每 800ms 一次脉冲轻音。
- 11.4s 定格后收尾长音，12.0s 静音。

## 7. 交付边界与下游交接

- 本文件是**唯一权威分镜源**，animator 不得擅自改动毫秒时间点；如需调整，须在交付说明中列出偏差项（镜号、原值、新值、原因）。
- 交付物：`docs/storyboard.md`（本文件）+ `index.html`（动态分镜）+ 可选 `docs/shot-data.json`（与第 2 节一致的镜头数据）。
- **明确不交付**：MP4、WebM、GIF、任何视频编码产物；不写录制/转码脚本；不在页面上放置"下载视频"入口。若后续需要视频，应由独立环节接入录屏工具，本轮不做。
- 验收方式：浏览器打开 `index.html`，按第 3 节 6 个时间点截图，与本文档逐镜比对主体、动作、字幕与转场是否一致。
