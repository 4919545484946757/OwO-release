面向开发者的智能体 SDK

让任何应用拥有可编排的 Agent 能力

OwO Agent SDK — 轻量、可组合、可观测的智能体运行时，几行代码接入你的业务流程。

开始接入 查看源码

支持 Node.js 18+ 与浏览器 ESM，单文件引入，无强制运行时依赖。

三项核心能力

不是能力清单堆砌，而是你接入当天就会用到的三件事。

  • 可编排智能体

    用声明式配置定义工具与流程，模型自动完成多步推理与工具调用。单次任务最多串联 12 个步骤。

    agent.addTool(searchDocs);
await agent.run("总结本周发布说明");

  • 轻量接入

    单文件 SDK，标准 ESM 引入，无强制运行时依赖。npm 包体积 38 KB（gzip），冷启动约 12 ms。

    import { Agent } from "owo-agent";

  • 可观测与可控

    内置调用追踪与逐工具权限边界，每一步输入输出都可导出为 JSON 日志，便于调试与审计。

    agent.trace.on("step", console.log);

三步跑通第一个 Agent

  1. 1

    安装 SDK

    Node.js 18 及以上，一条命令完成安装，无需额外配置构建工具。

  2. 2

    注册一个工具

    工具就是一个带 name、description 与 run 的对象，函数体内写你的业务逻辑。

  3. 3

    发起一次运行

    把自然语言目标交给 agent.run()，SDK 负责规划、调用工具并汇总结果。

shell / js 
npm install owo-agent

import { Agent } from "owo-agent";

const agent = new Agent({ apiKey: process.env.OWO_API_KEY });
agent.addTool({ name: "searchDocs", description: "检索官方文档", run: async (q) => docs.search(q) });
console.log(await agent.run("列出新版本的三条变更"));

代码可整体选中复制，复制结果会在此处播报。

三个差异点

  • 零构建接入：直接 import，不需要打包插件或代码生成。
  • 权限前置：工具级白名单，默认拒绝未声明能力。
  • 可回放追踪：每次运行生成可回放的步骤日志，排查问题不用猜。
