# OwOBot 报名表演示

使用 [活动报名-演示数据.csv](活动报名-演示数据.csv) 创建一个测试项目。表内的姓名和号码均为合成数据，号码以七个 0 开头。

在项目群发起下面的任务。

> 整理活动报名表，生成报名统计和脱敏明细。统计文件命名为 报名统计.md，用两列表格列出 A组、B组、总计及各自人数。明细命名为 报名明细-脱敏.csv，保留姓名、分组、手机号三列。手机号前七位替换成星号，只保留后四位。

批准交付后，可在仓库根目录运行验证。将参数指向实际收到两份成果的目录。

```powershell
python agent-sdk/owobot/demo/verify_signup.py D:\path\to\delivery
```
