# OwOBot source provenance

OwOBot integrates the open-source edition of [OpenMausBot v0.1.158](https://github.com/milind-soni/OpenMausBot/releases/tag/v0.1.158), commit `a988d43206971d685b4198a6428b881a46035b4a`. The files in `upstream/` were checked against the pinned Git blob IDs on import. The import excludes `enterprise/`, upstream GitHub and developer metadata under `.github/`, `.claude/`, `.tmpexp/` and `.oss-scanner/`, and large documentation media. See [the upstream licensing boundary](upstream/LICENSING.md).
