# 前沿方向备忘（2026-11）

> 目的：只记录**有明确来源**的行业变化，以及本项目当前所处位置与下一步动作。
> 事实优先级：本项目源码/测试 > 本文引用的外部资料。

## 1. Agent Plugins 1.0.0 已成事实标准（2026-08-06）

Amazon / Microsoft / OpenAI / Vercel / Cursor 同日采用，Google 同日加入 TSC；VS Code、
GitHub Copilot、Cursor、ChatGPT、Kiro 已集成。规范 = `plugin.json` + `skills/` +
`mcp.json`（可移植包）。
来源：[Forkast 报道](https://forkast.news/industry-shipped-agent-plugins-1-0-while-the-standards-body-debated/)

**我们的位置**：已实现兼容层（清单闭模式/技能发现/MCP 双传输/窄失败边界），并有
随包示例与安装生命周期。**下一步**：把市场分发从历史格式扩到规范包（签名策略分层）。

## 2. Agent Skills 已捐给 AAIF（Linux 基金会，2026-10-22）

连同名称/Logo/组织/域名移交；70+ 平台集成、约 100 万技能、近 2.8 亿次安装。
来源：[TechRepublic](https://www.techrepublic.com/article/news-anthropic-agent-skills-foundation-handover/)、
[钛媒体](https://www.tmtpost.com/agent/ai-article/21407)

**我们的位置**：技能是 `SKILL.md` + frontmatter，插件可携带技能并随启用状态加载。
**下一步**：技能来源标记（宿主/插件）、按需装载的 token 预算实测。

## 3. 工具检索（tool search / defer loading）成为刚需

工具数超过约 100 时，"全部塞进上下文"会显著掉准确率；业界做法是**语义检索 + 延迟加载**，
Anthropic Tool Search 报告约 85% token 下降（`defer_loading`）。
来源：[Agentic Landscape 2026](https://github.com/tylerjrbuell/reactive-agents-ts/blob/4d3fe980888c3d0d5239361b1f35077837f978d8/wiki/Research/2026-06-29-agentic-landscape-vs-reactive-agents.md)

**我们的位置**：有 MCP schema 预算压缩与工具名前缀掩码，但**没有**"按需检索工具"。
**下一步**：先在可选工具组（如 playbook 四件套）上做 deferred loading 实验，量化 token
与命中率，再决定是否引入检索。

## 4. KV-cache 前缀稳定性：掩码而不是移除

生产经验（Manus）：缓存命中 ≈ $0.30 vs 未命中 $3（约 10×）；频繁增删工具会抖动前缀、
让模型引用已消失的工具。原则是 **mask tools, don't remove them**。
来源：同上（Agentic Landscape，Manus 生产指标）

**我们的位置**：MCP 工具已走 `set_tool_prefix_enabled` 掩码而非卸载；可选工具组是
"默认不装配"（这会在开关时改变前缀）。**下一步**：给可选组设计稳定前缀策略
（装配但默认掩码），并加缓存友好性说明。

## 5. 上下文工程的下一阶段是"harness 工程"

LangChain 2026-11 复盘：架构已收敛为"模型循环 + 工具 + 沙箱"，难点转向
上下文重置/状态外置/失败转规则等 harness 层能力。
来源：[LangChain blog](https://www.langchain.com/blog/context-engineering-challenges-late-2026)

**我们的位置**：已有 turn 截止时间、压缩、审计、验收收据、剧本进度外置；
缺的是"失败自动转规则"的闭环。**下一步**：把高频工具失败沉淀为 playbook 的
`check` 断言或 hook（可审计、可回滚）。

## 优先级建议

1. **工具进入方式**（趋势 3/4）：先度量再改，避免为了省 token 破坏前缀稳定性；
2. **技能/插件分发**（趋势 1/2）：规范包进市场；
3. **失败转规则**（趋势 5）：与 playbook/hook 结合，做"从事故到检查项"的最小闭环。
