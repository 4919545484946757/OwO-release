## 六项实际行为

| 项目 | 已实现的结果 | 主要位置 |
|---|---|---|
| 自定义模型凭据 | 桌面壳使用 safeStorage 加密保存，Windows 原生验证为 DPAPI；页面只得到配置、是否有密钥和受限引用。重启前扫描本应用曾使用的回环端口，隔离加载旧来源并迁移；只清理成功且未变化的数据，冲突保持可恢复并提示。新地址/协议必须重新输入密钥；撤销后核心拒绝引用，不回落到默认密钥。 | electron/custom-model-vault、legacy-model-migration、custom-model-broker；server/desktop_model_credentials；gateway/custom |
| 会话事实恢复 | SQLite 提供最新回合、终态、统计；会话重开与核心重启后显示宿主记录的实际模型、用量与回执。新失败/中断不会继承旧成功记录；没有统计时明确显示未知。 | SessionStore、SqliteSessionStore、session_api；web/session-facts、app-domain |
| 项目首页 | 当前工作区最近会话、待人工处理、团队运行、交付入口与环境信息；工作区路径规范化并排除归档。团队计数明确是本机全部项目。起步示例只预填草稿；读取失败显示未知或错误。 | web/home.panel、workbench-navigation |
| 产物与证据 | 团队清单、版本、哈希、大小、格式校验、证据引用、未解决问题、正文、下载、历史与人工评审；会话模式显示宿主完成记录与前后文件变更，并可导出摘要。评审绑定版本、幂等键，权限仍由宿主检查；格式正确与行为验收分开。 | web/evidence.panel；Electron 下载 IPC；既有 Artifact/Review API |
| 执行与恢复 | 显示运行阶段和停止中；停止提交当前回合身份，等待宿主取消终态。历史失败可看证据、恢复原输入、经明确操作重试；草稿保留，观察已有活动回合不重新提交任务。恢复查询有分页、截止时间与离页释放。 | web/turn-recovery、app-domain、app |

## 大创创新下一步

这轮提供了可核验的基础，但没有实现或宣称完整“证据图、计划失效传播、自适应策略效果”。

推荐将研究主线收敛为：**面向学生项目的可验证人机协作 Agent 工作台**。优先验证两个研究问题：
1. 声明与交付证据对齐能否减少错误接受未验证结果、缩短证据定位时间？
2. 人工修改输入/计划后，显示受影响结果和重新验收范围能否提高受控失败的恢复率？

自适应单 Agent/团队作为第三个受控变量，先与固定单人、固定团队进行同模型、同任务、同工具、同权限、同预算的对照，记录质量、实际用量、耗时和失败恢复；缺 usage/单价标未知。桌宠适合作为状态入口，不能单独承担研究创新。具体实验规模、人员和时间需根据项目资源安排，不预填性能提升或首创结论。
