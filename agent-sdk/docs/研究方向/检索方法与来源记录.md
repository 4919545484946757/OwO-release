## 收录和核验

论文先读取出版页标题、作者和摘要，核对编号与预期主题，再下载 PDF，解析页数并提取前三页。标题不符的候选不下载、不计入资料库。新论文保存出版页 HTML、元数据、文件哈希和可识别的 PDF 版本。

项目先确认公开默认分支的完整提交号，再取得固定提交源码。GitHub API 限流后使用公开 Git refs 继续核对身份。源码包过滤二进制、安装依赖、生成目录、实验运行输出与录制响应；保留排除清单。CrewAI 为选定核心模块包，其他新包为筛选后的文本源码快照，均不是可直接复现实验的完整安装环境。

每个项目生成阅读卡片，提取最多 12 个模块供离线浏览，记录源码声明及哈希。目录声明用于定位，不表示完整语义审查或运行验收。

## 发现和修正

候选 MetaGPT/AutoGen、OSWorld、tau-bench/AgentDojo、InjecAgent 的部分种子编号与标题不匹配，已查原始来源纠正。原失败候选保存在 [记录](研究资料库/metadata/rejected-seeds.json)，不会混入已下载清单。

Letta 的默认仓库是迁移说明，新增当前 letta-code 源码。旧 Strands SDK 地址重定向到 harness-sdk，清单保存实际仓库。GitHub 未返回许可标识时保留“未确认”，以包内许可原文为准。

## 阅读与验证深度

本轮完成论文元数据、摘要及前三页提取；重点主题结合已有论文与项目部分源码声明综合整理，没有逐篇完成全文精读或复现实验。各专题的机制建议属于研究推论。全部 PDF、ZIP 和选读文件做结构或哈希检查，具体结果见资料库校验记录。

[资料库](研究资料库/README.md) 内有 BibTeX 和可追溯清单。48 篇论文均已补齐作者字段；前一批的作者从原始出版页或 PDF 首页核对。正式引用仍应核对论文版本、会议/期刊信息与 BibTeX 格式。
