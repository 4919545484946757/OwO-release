## 目录约定

```text
docs/
├─ architecture/    架构边界、源码导航和拆分台账
├─ guides/          操作与开发说明
├─ plans/           开发设计参考；archive/ 保存早期方案
├─ reports/         专项审查与阶段记录；archive/ 保存历史报告
├─ adr/             架构决策记录
├─ qa/              验收计划、原始证据和日志
├─ review/          专项复核包
├─ internal/        内部维护台账及文档整理记录
└─ 研究方向/        主题调研、发展建议、论文和固定版本源码
```

## 阅读时怎样判断证据

设计建议说明想做什么；源码审查说明当时看到什么；运行记录只证明其指定版本和环境下发生过什么。历史文档中的行号、测试数和“已完成”不自动适用于当前版本。

`ARCH-MICROKERNEL.md` 保留为旧源码注释的跳转入口，完整正文在 architecture/。QA 的原始证据、日志、安装快照保留原路径，便于已有引用继续追溯。既有研究草稿 `研究方向/参考项目.md` 保留。
