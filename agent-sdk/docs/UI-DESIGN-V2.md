# UI Design v2 · 对标 Codex / DSH 的收口记录

> 加载顺序：`style.css` → `visual-polish.css` → `product-shell.css` → `experience.css`
> → `team-delivery.css` → **`design-v2.css`**（本层只覆盖视觉，不改结构/交互）。
> 证据：`docs/qa/evidence/ui-v2-*.png`（1440×900/1000 真实 daemon 渲染）。

## 1. 设计取向

- **一个强调色**：绿色只用于主操作、激活态与进度；其余是暖中性色。
  不允许每个卡片自带一种颜色（旧界面最大的"AI 味"来源）。
- **一套密度**：控件 26 / 30 / 32 / 34px 四档；圆角 9 / 13 / 18；间距 4 的倍数。
- **一列内容**：对话 780px、面板 1120px、设置 760px，全部居中；
  正文一行不超过 ~70 字符。
- **两级层次**：页头（标题+说明）> 内容卡片；卡片内部只用间距和字重分层，
  不叠边框+阴影+背景三重。
- **不堆装饰**：无渐变霓虹、无玻璃拟态、无 emoji 图标；图标保持 16px 线性。

## 3. 与 Codex / DSH 的对应

| 模式 | Codex | DSH | 本界面 |
|---|---|---|---|
| 侧栏 | 固定窄栏，会话列表为主 | 左侧工作区/会话 | 236px，顶部工作区、中部入口、下部会话 |
| 主输入 | 居中浮层，工具条在框内 | 输入框 + 模式 | 780px 浮层，项目/审批/模型在框内 |
| 信息密度 | 紧凑，弱化装饰 | 中性、克制 | 统一 13/14px 正文、30px 行高控件 |
| 强调 | 少量品牌色 | 少量主色 | 单一绿色，只标主操作与进度 |
| 面板 | 独立页面式 | 插件页/设置页 | 面板页头 + 内容列 1120px |

## 4. 已知未做

- 深色主题：当前 tokens 仍以浅色为主，`data-theme` 未接入本层。
- 设置页「配置/外观」等子页尚未逐页核对（通用样式已覆盖）。
- 聊天消息的代码块/工具卡片样式沿用旧层，未在真实模型会话下复核。
- 动效只做了 transition，没有页面级转场。

## 5. 约束

- 本层**不修改** HTML 结构与 JS 行为；新增面板若需要单列，声明
  `data-layout="custom"`，否则会被通用两列网格接管。
- 颜色/圆角/间距改动优先改本文件顶部变量；不要在组件里写死。
