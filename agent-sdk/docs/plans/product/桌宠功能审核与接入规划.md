## 三、接入 Agent 改动清单（标准档 · 已确认）

> 原则：改动全部收在 app.js 桌宠薄层内（+ pet.js 一处单击分支），不新增 OwoPet 接口。

1. **回合完成摘要**（气泡带数据）

   - 兜底：diff 读取失败时回落「完成」
2. **工具失败气泡**
   - 位置：`pushToolResult` 的 `!payload.ok` 分支（L488）
   - 文案：`「read_file」失败了` hold 4s；后续阶段事件自然覆盖（`petSetState` 内部会清 hold 定时器，无残留）
3. **模型轮次提示**
   - 位置：SSE `progress` 中 `payload.message === "模型调用"`（L3072）
   - 文案：`第 ${state.turn.modelCalls} 轮思考…`
4. **审批直达**
   - 位置：pet.js `endDrag` 单击分支（L537–541）
   - 逻辑：若 `#approvalBar` 可见 → `scrollIntoView` + 聚焦允许按钮；否则原有聚焦 `#prompt`
   - 不改 OwoPet 接口（pet.js 本就直读 DOM，与现有 `#prompt` 读法一致）
5. **压缩提示**
   - 位置：SSE `compaction`（L3125）
   - 文案：`上下文已压缩` hold 4s

**深度档（可选追加）**：长任务计时（thinking 超 30s 气泡带秒数）、审批结果台词已在 G5 覆盖，无需另做。

## 五、风险

| 风险 | 说明 | 规避 |
|------|------|------|
| 完成摘要与汇报卡渲染竞态 | diff 请求慢时气泡先「完成」后改摘要 | 摘要只由 `renderTurnSummary` 触发，顺序固定 |
| hold 定时器误清当前态 | `petSetState` 每次清旧 timer，后续阶段事件可能提前结束「完成/失败」展示 | 已有语义即如此，可接受 |
| 删除互动后遗留 CSS/常量引用 | jump/✦/POKE_LINES/划动记账逐一清理，勿留死代码 | 第二节「删除与改造清单」逐条勾选 |
| 单击分支改动影响输入框聚焦 | 单击立即聚焦；仅审批栏可见时改道审批栏 | 断言无审批时聚焦 `#prompt`、双击不打断聚焦 |
| 双击识别窗口（~240ms）误判 | 慢速两次单击可能被判成一次双击 | 采用原生点击节奏判定（间隔内第二次点击才触发），不引入新延迟 |
