# 设置中心自动保存

点击导航栏顶部的“OwO 输入法”标题，或选择“通用设置”，可以开启或关闭“自动保存设置”。默认开启，该开关立即保存到配置目录中的 `settings-ui.json`，不会改变输入法配置协议。

开启时，输入方案、候选、学习排序、快捷键、中文标点及插件声明式配置会在停止修改约 450 毫秒后自动保存。连续操作会合并；手动保存按钮仍可使用。关闭时，配置修改需手动保存。

加载或重新加载配置不会触发自动回写。无效配置或写入失败会保留已保存文件并显示错误。关闭窗口前会等待待保存任务，失败时可返回修正，或明确放弃尚未保存的修改。

插件配置保存会通知候选框刷新。插件安装、启停、卸载、权限授权等操作不属于自动保存，不会被自动执行。

偏好持久化定向测试：`dotnet run --project tests/settings_center/preferences_tests.csproj`。
