# 项目风险清单

| 风险 | 影响 | 当前缓解措施 | 决策点 |
|---|---|---|---|
| TSF 编辑会话、线程和宿主差异 | 输入失败或宿主崩溃 | P1 最小探针、HRESULT 全检查、宿主矩阵 | P1 |
| IPC 过早冻结 | 兼容与迁移成本 | 可替换编解码层，原型不声明稳定 | P1/P3 |
| Core Service 失联 | 基础输入不可用 | 超时、重连、明确降级与最小本地状态 | P1 |
| 旧异步结果覆盖新输入 | 错误候选或上屏 | request ID 与 context generation | P1 |
| WinUI 3 部署复杂度 | 安装体积和失败率 | 设置中心独立进程，候选窗保持轻量 | P3 |
| 插件沙箱能力被高估 | 数据泄露或主服务受损 | 进程隔离、最小令牌、权限代理 | P3 |
| 模型格式/运行时不兼容 | 体积、性能或许可失败 | Mock 优先，逐模型基准与许可审查 | P3 |
| Unicode 数据版本/许可 | 转换结果不一致 | 构建期固定版本、哈希和许可证 | P4 |
| 用户数据损坏 | 学习数据丢失或无法启动 | 原子写入、校验、备份和恢复测试 | P2 |
| 日志泄露输入内容 | 隐私事故 | 默认不记录正文，显式调试与自动清理 | 全阶段 |
