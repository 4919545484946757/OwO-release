# 语气草稿输入法链路（L4 / L5）

更新：2026-10-22。源码已接入“选区 → 生成 → 预览修改 → 显式确认替换 → 反馈”。这是可构建并经过自动化检查的实现，真实模型质量、实际应用 TSF 人工交互和安装验收尚未完成。

## 怎么使用

先在设置中心开启授权语料学习、对应起草开关和目标应用所属场景，保证应用符合允许/排除列表且学习未暂停。需要已有同场景语料；缺少语料时显示诊断。敏感、只读、未知输入安全状态或无法捕获唯一选区的目标不会启动生成。

1. 在 **同一个可编辑输入框** 里选中要回复的文字，按 `Ctrl+Shift+R`；续写时选中已经写好的开头，按 `Ctrl+Shift+J`。这两个快捷键仅在对应功能开启、未启用插件输入方案且没有未提交拼音时使用。
2. 生成期间原选区不变，Esc 可取消。预览窗口不激活，也不改变原应用的焦点。
3. `F6` 切换过滤后最多 3 条候选；没有足够合格草稿时允许少于 2 条，不用未通过检查的内容凑数。
4. `F7` 进入 / 结束修改。中文使用当前原生输入方案的拼音候选，空格或数字选择，Enter 接受原始输入。左右/Home/End 移动预览光标，退格/Delete 修改文字。预览有独立光标和滚动条。修改模式不支持选区编辑、剪贴板快捷键或完整文本编辑器功能。
5. `Ctrl+Enter` 在没有未确认拼音时确认，**替换最初选中的文字**；不会替应用点击“发送”。用户手动修改后的文字按其显式确认提交，不再强制用模型事实规则拒绝用户新增内容。
6. Esc 放弃当前展示的草稿。关闭、切换应用、移动原选区或修改原文档会使目标作废；这些自动取消不推断为拒绝偏好。
7. 写入后光标和文档未变化时，紧接的 `Ctrl+Z` 精确恢复原选中文字；恢复回读成功才将对应反馈改为撤销。发生别的编辑/焦点变化后由应用接管撤销，不猜测与本草稿的关系。

当前回复模式是“所选文字作为消息，同时作为替换目标”。不支持读取聊天记录后去另一个输入框自动回复，也不承诺只读聊天气泡可作为 TSF 目标。真实宿主对选区、InputScope、回读和原生撤销的支持仍须逐个验收。

## 模型配置与发送约束

纯文本生成在单独后台线程执行，使用 Windows WinHTTP 和系统 JSON 解析，接口为 OpenAI 兼容非流式 `POST <base>/chat/completions`。它没有工具声明、工具执行或 Agent 会话；不改变现有 Agent 连接器授权。

配置只从触发进程环境读取，不写入源码、配置文件、日志或反馈：

| 环境变量 | 用途 |
| --- | --- |
| `OWO_TONE_BASE_URL` | 显式模型地址，例如本地模型的 `http://127.0.0.1:端口/v1`；无默认远端 |
| `OWO_TONE_MODEL` | 显式模型 ID；不猜测机器上已部署的模型 |
| `OWO_TONE_API_KEY` | Bearer 凭据；远端必需，本地可空 |
| `OWO_CLOUD_ENABLED=false` | 额外禁止远端语气模型调用 |

本机地址只认字面 `127.0.0.1` / `::1`，不通过 DNS 别名判断。HTTP 仅允许这些回环目标；其余必须 HTTPS 且 `tone_cloud_model_enabled=true`。回环连接不用代理。所有请求禁止重定向、Cookie 和自动连接认证；TLS 仍使用系统验证。没有读取用户级注册表环境变量的隐式逻辑，已有宿主进程需继承这些变量后再触发。

发送前重新读取有效主配置，配置不可读时不以备份授权继续发送；返回后再次核对配置快照，变化则丢弃结果。输入法也检查敏感字段、应用、场景、学习暂停和原目标有效性。只发送当前所选消息、风格摘要、最多 4 条当前允许应用的同场景例句、手写偏好、最多 3 条反馈提示和固定指令。例句/反馈在发送前再次做敏感信息过滤，敏感手写偏好或当前消息会拒绝发送。

请求限制 `max_tokens=768`；响应总量最多 64 KiB、正文最多 8 KiB。只接受单一 choice、`finish_reason=stop`、纯字符串 content，拒绝工具/函数调用和截断输出，再走 L4 事实、照搬、去重、大小与控制字符检查。读取有限时并可取消；失败显示固定诊断，不把服务错误正文、密钥、语料或提示写进日志。

## 写入与反馈

复用原有不可变 TSF context、选区 clone、内容 SHA-256、编辑观察和输入安全检查。最终确认在同步读写编辑会话中重检当前文档、原选区和哈希，尝试写入前消耗目标；任何失败/不确定结果都不自动重试写入。

RichEdit 复用现有原生写入验证；其他 TSF 宿主还要求 SetText 后精确回读，确认成功才记采纳/修改。生成或预览修改文字从不通过普通用户输入学习路径进入授权语料；成功回写的语言上下文明确标记 `user_authored=false`。

即时撤销凭据只在成功写入并重新捕获末尾光标后保留。撤销检查同文档、同光标、敏感状态及光标前精确提交文本，只恢复这一次替换；反馈通过 `ToneFeedbackStore::undo` 在写锁内替换原记录，同时清除含旧记录的备份。反馈写盘失败不撤回已成功的文档写入；文档可即时恢复，但无法认定不存在的反馈已回滚。
