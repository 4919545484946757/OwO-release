# 风格档案（L3）

设置中心“学习与排序 → 我的风格”展示一份按场景统计的写作习惯档案，并允许用户写下自己的偏好。它只读取 L1 的授权语料（见 [authorized-corpus-learning.md](authorized-corpus-learning.md)），所有统计都在本机完成，不调用模型、不上传。

## 按什么分场景

场景由**应用可执行名**推断，不看文字内容，所以同一句话只会落进一个场景，映射也便于核对：

| 场景 | 应用（不区分大小写） |
| --- | --- |
| 聊天 | WeChat.exe、Weixin.exe、QQ.exe、QQNT.exe、TIM.exe、Telegram.exe、Discord.exe、WhatsApp.exe、Line.exe 等 |
| 工作 | WINWORD.EXE、EXCEL.EXE、POWERPNT.EXE、OUTLOOK.EXE、WPS.exe、Feishu.exe、DingTalk.exe、Teams.exe 等 |
| 其他 | 其余全部 |

设置里的三个场景开关对应 `style_scene_mask` 的第 0、1、2 位。关闭某个场景后，档案不再统计它，按语气起草（L4）不会取用该场景的例句，从草稿学到的说法（L5，见 [tone-feedback.md](tone-feedback.md)）也不再参与该场景的请求与排序。

## 统计哪些特征

`engine/style_profile.*` 对每个场景输出：

- 样本句数、平均句长（按 Unicode 码点）、短句（≤12 字）占比；
- 句末带终止标点（`。！？…!?`）的比例；
- 每句感叹号、问号、省略号、逗号的平均次数；
- 重复出现至少 2 次的口头语（最多 8 个），按次数排序；
- 正式程度 0–100，以及组成它的每一项加减分。

正式程度以 50 为基准，各项都是**有上下限的小幅加减**，报告里逐项列出，例如：

```
- 正式程度：66/100（偏正式）
  - 句末带标点 100%（+10）
  - 每句逗号 0.3（-2）
  - 每句工作用语 4.0 处（+8）
```

因此用户可以把每一项加回去，得到同一个分数；没有黑箱权重。

## 边界与已知误差

- 只看最新 6000 条语料（与下一词联想一致），避免语料很大时查看档案出现停顿。
- 少于 5 句的场景不出分数，只报告测得的数字，并注明“样本不足”。
- 口头语按子串匹配，可能把其他词里的同一个字算进去（例如“酒吧”里的“吧”），所以只把出现 ≥2 次的词列为习惯，且它只是提示，不是词性标注。
- 档案是**汇总结果**：不输出原句，只输出数字和重复出现的口头语。删除语料后刷新即可看到变化。
- 手写偏好是一行自由文本（≤512 字节）。文件格式把 `~` 存成 `~~`，设置中心读回时还原；多行内容在保存前会被替换为单行，避免整份配置写入失败。它不会自动改写，也不会覆盖统计结果。

## 设置与命令行

设置中心“我的风格”页：场景开关、手写偏好、档案正文和“重新统计”。场景和偏好属于普通配置字段，受自动保存、保存/重新加载/重置本页控制。

命令行查看档案：

```bash
owo_corpus_shell style
```

它读取当前用户的语料与配置；`--corpus <路径>`、`--config <路径>` 可指向其他文件。

对应配置字段（schema 19 引入，现随 schema 20 一起保存；本页字段本身未变）：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `style_scene_mask` | `7` | 参与统计的场景位掩码，0 表示全部关闭 |
| `style_preferences` | 空 | 用户手写的一行偏好，`~` 转义为 `~~` |

## 验证

- `owo.engine.style_profile`：场景映射、口语/正式两组样本的分数差异、分数可由各项加回、口头语阈值、短样本不出分、场景掩码、最新 6000 条上限、非法 UTF-8 跳过。
- `owo.engine.corpus_shell_style`：预置加密语料后 `style` 输出两个场景、只含汇总不含原句；关闭工作场景后只剩聊天；全部关闭时给出说明。
- `owo.config.store` / `owo.config.shell_integration`：schema 19 往返、`style_preferences` 转义与单行限制、非法掩码被拒绝、`set` 与 `set-all` 传参。
- `tests/settings_center`：`~~` 还原、换行折叠、悬空 `~` 被拒绝；反馈概要与记录行的格式化（L5 页面复用同一套场景划分）。
- 尚未在真实设置中心窗口里做人工点击验收；以上为 Debug 构建下的自动化结果。
