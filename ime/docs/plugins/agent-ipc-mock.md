# 模拟第三方 Agent 测试工具

`owo_agent_mock` 是只用于本机开发测试的第三方 Agent 示例。它与 OwO 通过默认命名管道通信，不加载进输入法、Core 或插件进程。

## 启动

双击项目根目录的 `start-agent-mock.cmd`。脚本会构建并启动模拟服务，控制台保持打开期间服务有效；按 Ctrl+C 可停止。

默认管道：

```text
\\.\pipe\OwO.Agent.External.v1
```

控制台会显示收到的自然语言、原始/分割拼音、已选和剩余输入、当前应用、带应用标识的局部上下文、请求/会话/幂等 ID、动作和指令 ID。测试时不要输入真实密码、令牌、支付信息或其他秘密。

## 首次准备

1. 在设置中心安装 `org.owo.agent-ipc-1.3.0.owopkg`。
2. 阅读 Agent IPC 权限与隐私说明，勾选明确同意后启用。
3. 保持模拟 Agent 控制台运行。
4. 在新的输入窗口中使用 OwO 输入法。

## 建议测试流程

输入：

```text
vbangwozhaowenjian
```

先用数字键或鼠标选择拼音候选，确认文字只暂存在 `v +` 后面。完整消耗请求后会自动
发送；也可在尚有拼音时按 Enter 或 Space 显式发送。

模拟 Agent 首页会返回：

1. `回显本次请求`：返回实际收到的用户请求并完成会话；
2. `显示收到的应用上下文`：显示收到的程序名、窗口类和局部上下文；
3. `模拟执行中状态`：先返回 `executing`，下一次轮询返回 `completed`；
4. `模拟删除文件（高风险测试）`：标记为高风险，OwO 应拒绝在候选框直接选择。

请求声明 `output.effects`（控制台 `output.effects=yes`）时，首页最前面还有三个 v4 回写验收候选：上屏测试文字（`commit_text`）、错投目标（绑定错误的 `context_id`，应只预览）、复制到剪贴板（`copy_text`）。验收步骤见 `docs/integration/工程文档.md` 第 4.1 节。

下一页包含“模拟完成任务”和“模拟 Agent 错误”。按 Escape、删除开头 `v` 或关闭候选框时，控制台应收到相同 `session_id` 的 `cancel`。

协议 v3 的命令还包含描述、类别、风险级别、确认要求、操作预览和可用状态。模拟端会
缓存同一 `idempotency_key` 的结果，重复请求不会重复推进模拟任务，并会返回请求 ID、
状态版本、进度、重试等待时间和可取消状态。参考解码器仍接受 v2 请求并返回 v2 响应。

还应测试候选撤销：先选择一部分文字，在剩余拼音仍存在时按 Backspace。第一次应恢复
已选文字对应的原拼音，后续按键逐字删除，且在 `v` 本身被删除前不应收到 `cancel`。

跨位置上下文测试：先在记事本用 OwO 上屏一段文字，再切到另一个应用或同一应用的
另一输入位置上屏第二段，最后发起 `v` 请求。控制台应按顺序显示多个 `context_entries`，
每段具有独立 `context_id` 和对应的应用信息；不应出现窗口标题或密码框内容。

结构化槽位测试：输入 `vsanzhongtixingwokaihui` 并发送。模拟端会返回
`create_reminder` 任务草稿，以及“今天3点 / 明天3点 / 每天3点”三个候选。选择其中
一项后，控制台收到的 `select` 应只包含对应 `slot_updates`、原任务版本和命令 ID，
而不是再次收到完整自然语言。输入法不直接上屏候选文字，时间槽位变为锁定，事项槽位
和任务树保持不变；随后会出现“确认创建提醒”。

## 自定义管道

PowerShell 启动脚本支持：

```powershell
.\scripts\start-agent-mock.ps1 -PipeName '\\.\pipe\My.Agent.Test.v1'
```

同时需要在 Agent IPC 插件配置页填入完全相同的管道名。模拟服务为管道设置仅允许当前 Windows 用户、SYSTEM 和管理员访问的 ACL，不接受远程管道。
