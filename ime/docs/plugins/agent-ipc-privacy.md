# Agent IPC 连接器：权限与隐私说明

## 启用条件

该插件是高权限进程插件，默认不启用。首次启用以及插件版本变化后，设置中心都会重新显示本说明的摘要。只有勾选“我已理解并明确同意”后，当前精确版本才会获得授权。

授权包含 `agent.ipc`、`input.context` 和 `system.full_trust`。`system.full_trust` 用于连接用户配置的本机命名管道，并不表示第三方 Agent 可以绕过 OwO 的插件授权或替其他插件调用服务。

## 会读取和发送什么

只有拼音串以小写 `v` 开头，并且用户选择候选完整消耗请求或按下 Enter、Space 明确确认时，才会形成 Agent 请求。单独输入、尚未发送过请求的 `v` 可作为普通字母退出；已发送请求的会话不会借此把 `v` 上屏。插件最多发送：

- 去掉首字符 `v` 后的原始输入；
- 原始拼音、分割拼音、已选择文字、剩余拼音、纠错状态和最终自然语言；
- 随机生成的当前 `session_id`；
- 用于去重和关联状态的随机/递增请求 ID、父请求 ID及幂等键；
- 当前焦点的进程/线程 ID、可执行文件名、顶层窗口类、焦点控件类和不透明上下文 ID；
- 由 OwO 自身近期上屏的有限文本分段。每段都带独立上下文 ID 和对应的应用信息；默认只发送当前输入位置和**同一可执行文件**中记录的分段，其他应用的分段不跨应用发送；
- 用户选择的结构化指令 ID，或当前候选页码。
- 任务意图、槽位值、槽位与原拼音区间的映射、任务版本，以及用户选择造成的槽位补丁。

默认最多发送当前输入位置及最近 16 个历史上下文分段、每段 8192 UTF-8 字节、合计 32768 字节。用户可在
插件配置页降低这些值或把上下文总量设为 0；硬上限为 32 段、每段 32768 字节、合计
131072 字节。宿主只在 Core Service 内存中保留这些片段，Core 退出或重启后即清空。

默认不读取或发送：

- 窗口标题、完整文档、文件内容和光标周围由其他输入法或应用产生的正文；
- 剪贴板、浏览器历史、联系人；
- 键盘中不属于当前 `v` 会话的输入；
- 密码框或已识别安全输入框的局部上下文和应用标识；
- 第三方 Agent 未通过结构化协议返回的控制信息。

用户可以在插件配置页关闭应用标识或局部上下文，并可分别调整总量、单段长度和分段数量。关闭应用标识后仍保留随机、不透明的上下文 ID，以便第三方 Agent 区分片段边界，但进程/线程 ID、程序名和窗口类会被清空。敏感信息过滤不能被绕过；若过滤功能关闭、失败或收到无效 UTF-8，请求会被拒绝而不是原样发送。

## 脱敏边界

插件会分别过滤用户输入、结构化拼音/文字字段、槽位补丁值和每个局部上下文分段。目前会遮盖常见密码、令牌、密钥、凭据字段（含“密码/口令/验证码/校验码/动态码/卡号/身份证”等中文标签后的值）、通过 GB 11643 校验的 18 位身份证号、11 位大陆手机号、电子邮箱以及通过校验的支付卡号，并为上下文标记是否过滤、遮盖或截断。这是一层降低误传概率的保护，不是对所有自然语言秘密的完整识别。不要在 Agent 模式中输入密码、验证码、助记词、私钥、支付信息或不希望交给第三方的数据。

如果宿主把输入区域标记为敏感场景，当前请求会清空全部局部上下文和应用标识，且该输入位置产生的文字不会加入跨位置记录。标准 Windows 密码编辑框，以及通过 TSF InputScope 声明为密码、数字密码、PIN 或私密的输入区域会被识别；无法确认安全属性（InputScope 未知、只读、禁用或加载中）的输入位置同样按敏感处理。自绘控件若既不暴露安全属性也不经过 TSF，可能无法被可靠识别，因此用户仍应避免在任何登录或支付界面使用 Agent 模式。

## 第三方风险和责任边界

数据会发往配置的本机命名管道。OwO 不主动联网，但管道另一端的第三方 Agent 可能联网、记录请求、调用其他服务或执行系统操作，其隐私政策和数据保留规则由第三方负责。

OwO 只传递结构化请求、展示结构化结果并返回用户选择，不执行 Agent 的自然语言文本。删除文件、启动程序、修改系统设置、账户、支付、凭据等高风险操作不得仅凭候选选择执行。第三方 Agent 必须在自己的可信界面中再次展示操作对象、影响和风险，并获得用户明确确认。OwO 将 `high_risk: true` 的候选视为不可直接选择，只提示用户前往第三方 Agent 确认。

同一 Windows 用户下的其他进程通常也处于同一用户安全边界。请只连接可信 Agent，并为管道服务器配置仅限当前用户的访问控制。不要把管道暴露为远程命名管道。

## 会话和异常

- 删除已经暂存的候选时，OwO 会先把该候选恢复为原拼音；后续 Backspace 再逐字删除。只有明确删除开头 `v`、按 Escape、候选框关闭、输入焦点丢失或任务完成时，才会取消并结束会话。
- Agent 未连接、超时、崩溃、返回格式错误、过滤失败或会话 ID 不匹配时，不会执行指令。
- 异常不会提交原始输入；原输入保留在拼音预览区，便于重试、修改或退出 Agent 模式。
- 上下文分段和 IPC 内容不由 OwO 持久化，Core Service 重启后清空。第三方 Agent 是否保存数据取决于其自身实现。

撤销授权：在设置中心的插件页停用或卸载“OwO Agent IPC 连接器”。停用后新的 `v` 请求会显示 Agent 服务不可用。
