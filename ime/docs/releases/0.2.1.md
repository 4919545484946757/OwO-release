# OwO Input Method 0.2.1

面向 Windows 11 x64 的功能更新版本，重点加入高权限 Agent IPC 连接能力，并完善候选输入、设置中心和插件安全边界。

## 主要变化

- 新增以 `v` 开头触发的 Agent 模式，普通拼音解析、候选选择与 Agent 请求相互解耦。
- 新增高权限 Agent IPC 连接器，启用前必须展示权限、隐私和风险说明并取得明确同意。
- Agent 通信支持会话、状态、候选指令、分页、取消、超时、响应校验和敏感信息过滤。
- 密码框及安全输入场景禁止采集上下文，高风险操作仍由 OwO 宿主确认机制约束。
- 提供可移植模拟 Agent、独立 C++ 参考实现和第三方接入、隐私及联调文档。
- 改进候选预编辑、失焦保护、延迟上屏以及上下文识别的配置能力。
- 更新候选框主题插件、设置中心插件配置和安装向导入口。

本版本及 Agent 插件均未进行商业代码签名。安装前请核对发行目录中的 SHA-256 清单，并只连接可信的第三方 Agent。
