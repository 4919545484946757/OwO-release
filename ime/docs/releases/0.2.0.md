# OwO Input Method 0.2.0

面向 Windows 11 x64 的第二个正式发行版本，集中改进候选生成、候选分区、设置中心、
插件系统与安装体验。

## 主要变化

- 优化完整拼音、不完整拼音、纠错、长句和跨边界候选生成。
- 候选分区支持按输入意图调整首页单字区与字典区顺序。
- 改进候选分页、展开列表、鼠标交互、拼音光标和渲染稳定性。
- 完善本地词频学习、libime 上下文排序和基础候选降级路径。
- 设置中心改用 Windows 11 风格侧边导航、设置搜索和插件配置页。
- 安装向导增加中文语言支持检查及设置中心快捷入口选项。
- 官方候选皮肤更名为“OwO 亚克力候选框”，并采用当前验证配置作为默认值。

本版本仍未进行商业代码签名。安装前请核对发行目录中的 SHA-256 清单。
