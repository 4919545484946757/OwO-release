# OwO Input Method 0.2.3

这是面向 Windows 11 x64 的候选生成、显示稳定性与开发文档更新版本。

## 主要变化

- 改进 `wsm`、`nji`、`rwkyy` 等首字母和混合缩写的句子、字典词、单字候选覆盖。
- 保留候选来源分组，使基础候选与智能排序增量更新使用一致的首屏布局。
- 优化短句候选优先级，避免有效句子在分区后被推至页面末尾。
- 基础候选先行返回，昂贵的补全结果在请求仍有效时再增量更新；旧请求可被新输入取代。
- 候选窗口调整尺寸时抑制中间空帧，并在主体绘制完成后更新阴影，减少连续输入闪烁。
- 更新 README、插件 API v1、Agent 权限隐私、第三方接入和模拟工具文档。
- Agent IPC 连接器与可移植 SDK 提升至 `1.0.1`，确保包内文档变化具有独立版本和摘要。
