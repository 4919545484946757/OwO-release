# ADR-0004：词库来源、许可与构建边界

- 状态：P2 已接受
- 日期：2026-07-31

## 背景

P2 计划使用雾凇拼音词库，但 OwO 仓库当前没有项目许可证文件。雾凇拼音官方仓库当前标注为 GPL-3.0-only，发布资产包含独立许可文件。源词库、清洗后中间文件和派生二进制的分发边界必须在导入前明确。

## 决策

1. OwO 项目采用 `GPL-3.0-only`，与雾凇拼音仓库声明的许可证保持一致；根目录保留完整 GPLv3 许可证文本。
2. 首个锁定上游为雾凇拼音标签 `2026.06.30`、提交 `6810e8916d160498620a16fef2135956fecbd485`。导入 manifest 必须记录官方下载 URL、源文件 SHA-256、许可证标识和导入器版本。
3. P2.2 保持与具体上游解耦的词库编译器、版本化二进制格式和严格读取器。功能和损坏测试继续使用仓库内最小项目测试数据，不冒充雾凇子集。
4. 仅导入具有显式拼音编码的词条。`tencent.dict.yaml` 等依赖 Rime 自动注音的数据在 OwO 拥有等价、可验证的注音流程前失败封闭，不猜测读音。
5. 构建工具对缺失来源 manifest、未知格式版本、非法 UTF-8、越界字段和重复冲突失败封闭。分发派生 `.owolx` 时必须同时提供 OwO 源码、GPL 文本和上游来源 manifest。

## 影响

- 可以在不承担未审核外部数据的情况下完成紧凑词典技术闭环。
- 许可选择门禁已解除，但真实词库导入、未注音词条处理与规模复测仍是独立技术门禁；完成前不得宣称完整雾凇数据已集成。
- 本 ADR 不是法律意见；对外分发前仍需开发者确认项目许可策略。

## 回滚

删除外部导入适配器和相关 manifest 即可；通用词典格式、读取器与项目测试夹具不依赖雾凇数据。
