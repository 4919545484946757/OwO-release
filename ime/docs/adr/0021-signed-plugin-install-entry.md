# ADR 0021：设置中心签名插件安装入口

- 状态：P3C 已采用
- 日期：2026-08-02

## 背景

P3C 已有唯一高层安装事务，但此前只有测试代码调用它。用户无法从设置中心选择 `.owopkg`，固定管理后端也没有安装命令。若 UI 自行拆分预检、信任、解包或发布步骤，会重新引入绕过验证和不完整事务的风险。

## 决策

1. `owo_plugin_shell <store-root> install <package-path>` 是设置中心唯一安装后端入口，只调用 `install_plugin_package`。文件路径通过进程参数列表传递，不经过命令解释器；后端仍独立重验扩展名、包结构、不可变快照、发布者信任及存储边界。
2. 安装命令无论成功或失败都向标准输出返回 schema 1 JSON，包含稳定阶段、是否发布、是否激活、插件身份、安装或保留暂存路径、清单摘要、已验证发布者证书绑定和诊断。失败同时写标准错误并返回退出码 2。
3. WinUI 设置中心使用与主窗口绑定的系统文件选择器，只显示 `.owopkg`。选择文件后必须展示精确文件名和路径，并在执行前确认：只接受通过 Windows 离线发布者信任的签名包，成功版本会原子发布并立即激活，本机证书链或吊销缓存不足会失败封闭。
4. UI 只把后端 JSON 视为结果与显示数据，不能据此替代后端验证。成功结果必须同时满足 `completed`、已发布、已激活和完整身份绑定；失败时展示稳定阶段和诊断，若清理失败还展示精确保留暂存路径并刷新恢复列表。
5. P3C 不提供未签名开发模式，也不提供直接调用低层暂存发布 API 的命令。文件选择取消发生在后端启动前；后端启动后由安装事务保证失败状态可审计。

## 结果

用户可以从设置中心完成一次明确、有反馈、不可降级的签名插件安装。命令行负向契约验证缺失包在 `package_inspection` 阶段失败且不初始化插件存储。发行签名证书与在线更新源仍不属于本决策。

## 回滚

移除设置中心安装按钮及 `owo_plugin_shell install` 命令即可回到只读/显式维护入口；高层安装事务、版本存储、既有插件和输入主链路不受影响。
