# 中文标点设置

在设置中心的“候选与输入”页点击“中文标点”文字、卡片空白或右侧箭头，进入独立页面。右侧总开关独立操作，不会触发导航。菜单文字和箭头也支持键盘聚焦及激活。

子页面为现有的 26 种英文标点键分别提供中文格式开关，展示实际转换结果。修改后点击“保存”；“重置本页”只恢复各项偏好，不改变总开关。也可通过顶部搜索查找逗号、引号等项目。

- 中文模式、总开关开启且对应项开启时，才转换该标点。
- 对应项关闭时，沿用英文按键输入行为；总开关关闭时所有项目都不转换。
- 英文模式不使用中文转换。`/` 不映射为顿号，顿号仍由 `\` 输入。
- 已存在的拼音分隔符、候选翻页快捷键优先级不变。
- 插件输入方案仍由插件处理标点，本体细分项不越过方案权限生效。

配置 schema 15 新增 `chinese_punctuation_mask`。它是保存各项偏好的位掩码，位顺序定义在 `config::kChinesePunctuationSources` 中，只能追加，不能重排。总开关仍为独立的 `chinese_punctuation_enabled` 字段。

旧 schema 迁移时默认打开全部既有转换，保留之前行为；细分偏好不会随总开关暂时关闭而丢失。包含未知位的配置会被拒绝，不会覆盖当前有效快照。
