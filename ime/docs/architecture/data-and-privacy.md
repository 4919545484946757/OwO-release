# 数据目录、日志与隐私基线

状态：P0 草案。

建议根目录为 `%LOCALAPPDATA%\OwO\InputMethod\`，其下按 `config`、`data`、`logs`、`plugins` 和 `cache` 分离。系统词典与用户词频必须分离。

- 普通配置使用版本化 Schema、原子替换和上一有效版本回退。
- P0/P1 暂不引入自研静态加密；依赖当前用户 ACL。密钥进入 Windows 凭据或安全存储，不进入普通配置。
- 是否加密用户词频保留为发布前决策；持久层必须可替换。
- 日志只记录时间、进程、模块、级别、事件 ID、请求 ID 和错误码。
- 默认不记录完整预编辑/上屏文本、剪贴板、选区、语音、截图、OCR 原文、密钥或敏感路径。
- 文本调试必须显式启用、有醒目标识并支持自动清理。
