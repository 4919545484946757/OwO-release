# OwO 输入法使用协议：输入环境与高级编辑

使用前请了解当前应用、网站、远程桌面及输入位置的性质，并确认自己有权在该环境使用输入法及相关服务。某些应用只向 Windows 提供普通输入所需的信息，无法可靠告知 OwO 当前控件是否包含敏感内容、是否适合读取文本或进行高级编辑。能够正常打字不代表该位置已通过安全验证。

- **普通输入**：如果能确认当前控件接收普通输入，OwO 继续按现有设置提供候选、排序、上下文处理、数据传输与学习功能。此类兼容环境不会自动关闭这些功能。请不要在无法确认其性质或不允许记录、处理或传输内容的位置输入密码、验证码、凭据或其他保密信息；应按需要改用系统提供的安全输入方式。
- **高级编辑**：在无法验证的窗口调用 `v` 高级功能时，OwO 会要求明确选择“仅本次信任”。确认后，选中文本功能可读取选区及按设置允许的邻近文字；选择具体功能后，相关内容将发送给所配置的模型。调用 IPC Agent 时，确认可能发送本次请求和按原有权限允许的上下文。确认不是对目标窗口的安全认证，不会永久保存，也不能覆盖明确的受保护状态或第三方功能的授权限制。
- **责任范围**：在适用法律允许的范围内，OwO 项目不对因用户误判输入环境、在未获授权的位置处理内容、或主动发送给其所选第三方服务造成的后果承担责任。第三方服务的数据处理遵循其自身条款，且本说明不排除或限制依法不得免除的责任。

对明确受保护的控件，本版本保留现有拦截；专用安全输入方式不在本次更新范围内。
