# OwO 亚克力候选框

官方声明式候选框皮肤示例。启用后候选框使用半透明深蓝背景，并可在设置中心的插件
配置页调整背景、边框、分割线、拼音文字、候选文字、候选块和候选序号的颜色与透明度，
也可启用本地高斯背景模糊并调整半径，或设置候选栏阴影的颜色、透明度、模糊半径和偏移。

此插件没有可执行代码、不联网、不读取输入内容，只申请低风险的
`ui.candidate_theme` 权限。配置热加载不会在 TSF 输入线程运行插件进程。

背景模糊由宿主渲染，不截取候选框自身。宿主保留独立的原始背景快照：展开、收起、
切换候选栏模式或改变位置重新取样时，用该快照还原旧候选框和阴影遮挡的区域，再做高斯
模糊；不会把上一帧的文字、高亮或阴影反复混入背景。遮挡区在当前组合态内沿用已有
背景，未遮挡区重新取样；关闭候选框后清除快照。若缺少可靠的原始背景，则暂时使用
普通半透明底色，不把不可信取样作为模糊输入。

重新取样不隐藏候选框、不切换屏幕捕获排除标志；皮肤仍可正常截图，无新增插件权限。
