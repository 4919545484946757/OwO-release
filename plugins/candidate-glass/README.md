# OwO 亚克力候选框

官方声明式候选框皮肤示例。1.3.0 默认跟随 Windows 应用明暗模式：深色使用半透明
深蓝背景，1.3.1 的浅色使用灰白黑配色：半透明灰白背景、深灰文字和黑灰高亮。
可在设置中心的插件
配置页调整背景、边框、分割线、拼音文字、候选文字、候选块和候选序号的颜色与透明度，
也可启用本地高斯背景模糊并调整半径，或设置候选栏阴影的颜色、透明度、模糊半径和偏移。

“候选框主题”支持跟随系统、固定浅色和固定深色。每套配色独立配置七类语义颜色及
阴影颜色/透明度；模糊半径、阴影开关、形状和偏移共用。已有 1.2.0 配置原样保留为
深色配色，缺少的浅色字段使用资源默认值，不覆盖或重写原配置。系统主题变化时热更新，
不销毁或隐藏候选窗口。此版本使用主题资源 v2，需搭配支持双配色的最新版宿主。

此插件没有可执行代码、不联网、不读取输入内容，只申请低风险的
`ui.candidate_theme` 权限。配置热加载不会在 TSF 输入线程运行插件进程。

## 分别调整浅色、深色配色

进入“设置中心 → 插件 → OwO 亚克力候选框 → 配置”。

1.4.0 通过“配置页”选项框切换公共效果、浅色配色、深色配色，只显示当前选中的页。
选页不改变候选框当前使用的主题，未显示页的修改仍会保留并一起保存。
每套主题扩展为 17 类独立颜色/透明度，包括序号底块、展开选中行、悬停/按下状态、
控制按钮背景/边框/文字、次要文字与光标。完整字段见项目的
`docs/plugins/candidate-theme-fields.md`；新版扩展角色需配套最新宿主使用。

- “候选框主题”选择“跟随系统”，会按 Windows 的应用主题自动切换；也可固定浅色或深色。
- 展开“浅色 · …”或“深色 · …”颜色栏，在同一栏内分别修改颜色和透明度。
  两套配色的背景、边框、分割线、拼音文字、候选文字、候选块、序号和阴影均独立保存。
- 透明度数值范围为 0–1：0 为透明，1 为不透明。开启背景模糊时，背景透明度实际控制
  底色混合强度：0 为纯模糊背景，1 为纯底色，不会取消或覆盖另一主题的透明度设置。
- 模糊开关/半径、阴影开关/半径/偏移属于公共效果，两套配色共用；阴影颜色和透明度独立。
- 自动保存开启时调整后自动生效，否则点击保存。编辑非当前主题只改变该主题的配置，
  切换到相应主题后才会看到效果。

开发者：深色沿用 `background_color`、`background_opacity` 等字段；浅色使用
`light_background_color`、`light_background_opacity` 等独立字段，其余颜色项同理。
不要把浅色值写回深色字段，也不要在切换主题时重置未编辑的另一套配置。

背景模糊由宿主渲染，不截取候选框自身。宿主保留独立的原始背景快照：展开、收起、
切换候选栏模式或改变位置重新取样时，用该快照还原旧候选框和阴影遮挡的区域，再做高斯
模糊；不会把上一帧的文字、高亮或阴影反复混入背景。遮挡区在当前组合态内沿用已有
背景，未遮挡区重新取样；关闭候选框后清除快照。若缺少可靠的原始背景，则暂时使用
普通半透明底色，不把不可信取样作为模糊输入。

重新取样不隐藏候选框、不切换屏幕捕获排除标志；皮肤仍可正常截图，无新增插件权限。
